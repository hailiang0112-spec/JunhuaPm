# 君华装修项目管理 · Mac 免安装版

这是一个双击即可打开的 Mac 应用（`JunhuaPm.app`）。电脑上不需要安装 Docker、Python、Node.js，也没有安装向导。

应用只支持 **Apple 芯片（M 系列，arm64）**。Intel Mac 不能运行这个包。应用没有 Apple 开发者签名，第一次打开需要按下面的方式确认。

## 下载

1. 打开本仓库的 GitHub Actions，进入名为 **macOS desktop app** 的工作流。
2. 选一次成功的运行（绿色勾），在页面底部的 **Artifacts** 里下载 `JunhuaPm-mac-arm64`。
3. 解压得到 `JunhuaPm-mac-arm64.zip`，再解压出 `JunhuaPm.app`。
4. 可以把 `JunhuaPm.app` 拖进「应用程序」，也可以放在任意文件夹里直接打开。不需要安装器。

## 第一次打开（Gatekeeper）

从网络下载的应用会被系统标成隔离。如果双击后提示「无法打开」或「已损坏」：

1. 在 Finder 里对 `JunhuaPm.app` **按住 Control 点按**（或右键），选择 **打开**。
2. 在对话框里再点一次 **打开**。
3. 若仍然提示已损坏，打开「终端」，把应用拖进窗口，或执行（路径按实际位置改）：

```bash
xattr -cr /Applications/JunhuaPm.app
```

然后再用右键「打开」一次。之后就可以直接双击。

第一次启动会在本机准备演示数据，窗口会停在「正在准备本地数据」大约一两分钟，这是正常的。

## 数据放在哪里

```text
~/Library/Application Support/JunhuaPm/
```

里面有数据库 `jh.sqlite3`、上传的文件 `files/`，以及日志 `backend.log`。在 Finder 的「前往 → 前往文件夹」里粘贴上面的路径即可看到。

想清空重来：先退出应用，把这个文件夹删掉或改名，再打开应用，会重新写入演示数据。

## 限制

- 只有 Apple 芯片（arm64）版本，没有 Intel 版，也没有通用二进制。
- 未做 Apple 公证。下载后第一次需要右键打开。
- 这是本机单人使用的桌面版，数据库是 SQLite，不是公司服务器上的 PostgreSQL。关掉窗口就会退出，并停掉内置的本地服务。
- 公司正式部署仍然用 `app/deploy/` 里的 Docker。桌面版不能代替那套部署。
