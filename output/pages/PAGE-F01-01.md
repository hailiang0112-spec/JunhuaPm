## 2. 页面概述

- **定位**：公司管理员查看公司全部工地，并从公司模板开新工地。
- **存在理由**：新工地不用从零录入上百项工作（US-F01-01、US-F03-01）；公司管理员需要一个看全公司项目的入口（AC-F01-04）。
- **不做什么**：
  - 不在本页改项目状态：状态由项目经理在 PAGE-F01-02 推进（AC-F01-11）。
  - 不删除项目：需求未提供删除。
  - 其他成员的「项目列表」是我的待办中的「我的工地」卡片（PAGE-F16-01），不是本页。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 公司管理员（周经理） |
| 设备 | 电脑为主 |

- **场景 A 开新工地**：点「新建项目」→ 填项目名称、地址、计划开工和交房日期 → 选「君华联排别墅标准模板」→ 创建 → 列表出现状态为「筹备」的新项目 → 去邀请成员。
- **场景 B 填错**：交房日期早于开工日期 → 字段旁提示，不创建任何记录。

## 4. 信息架构

1. 外壳：工地切换器显示「全部工地」，导航「项目管理」高亮。
2. 顶栏：标题「项目管理」、副标题「公司全部项目 4 个」、主按钮「新建项目」。
3. 筛选栏：状态 chips（全部 / 筹备 / 施工中 / 已交房）+ 名称搜索。
4. 项目表格（手机端在横向滚动容器内）+ 分页。
5. 新建项目弹窗。

| 按钮 | — | 取消 / 创建项目 |

## 6. 交互流程

```
点「新建项目」→ 弹窗
  → 点「创建项目」
      ├─ 缺项目名称 / 开工日期 / 交房日期，或交房早于开工 → 各字段旁显示原因，弹窗不关，不产生任何项目记录（AC-F01-02）
      └─ 通过 → 创建项目（状态「筹备」）并复制模板（AC-F01-01）
            → 关闭弹窗，列表顶部出现新项目，提示「已创建 云栖台 · 合院别墅，状态：筹备」
            → 提示中提供「去邀请成员」→ PAGE-F01-02
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常态 | 有项目 | 表格 + 分页（每页 20 条） |
| 加载态 | 读取列表 | 表格骨架屏 |
| 空状态 | 公司还没有项目 | 「还没有项目。从公司模板新建第一个工地。」+「新建项目」 |
| 筛选无结果 | 筛选 / 搜索无匹配 | 「没有符合条件的项目」+ 清除筛选 |
| 错误态 | 读取失败 | 「项目列表加载失败（网络中断），请重试」+ 重试 |
| 无权限态 | 非公司管理员打开本页链接 | 「仅公司管理员可访问公司管理页面」+ 返回我的待办（DEC-108） |
| 提交中 | 点创建 | 按钮不可重复点击 |

- **DEC-108（design-derived）**：本页与公司模板页是公司级页面，不属于任何项目，越权访问时不适用「无权访问该项目」文案，改为页内无权限态并提供返回我的待办；服务端同样拒绝（NFR-003）。

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 项目名称 | 提交时 | 非空 | 请填写项目名称 |
| 计划开工日期 | 提交时 | 非空 | 请选择计划开工日期 |
| 计划交房日期 | 提交时 | 非空 | 请选择计划交房日期 |
| 日期顺序 | 提交时 | 交房 ≥ 开工 | 计划交房日期不能早于计划开工日期 |

- 失败时一次列出全部问题（蓝图 §5），不产生任何项目记录（AC-F01-02）。
- 列表可见范围：公司管理员看到公司全部项目（AC-F01-04）。
