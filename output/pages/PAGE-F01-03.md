## 2. 页面概述

- **定位**：成员访问自己没有任何角色的项目时，明确告诉他无权访问，并且不泄露这个项目的任何信息。
- **存在理由**：项目之间数据隔离（REQ-F01-03）；被移除的成员下一次请求起就不能再访问（AC-F01-06）。
- **不做什么**：不显示项目名称、业主、地址等任何业务数据；不提供「申请加入」（需求没有该流程）。

## 3. 用户与场景

- **场景 A 点了别人转发的链接**：质检王工点开另一个工地的检查点直达链接 → 看到「无权访问该项目」→ 返回我的待办。
- **场景 B 已被移除**：成员被公司管理员移除后打开旧书签 → 同样显示本页。
- 未登录用户访问工地链接时先进入 PAGE-F02-01 登录页，登录后再判断权限。

## 5. 状态与边界

| 状态 | 页面表现 |
| :--- | :--- |
| 唯一状态 | 上表内容，无加载、空、错误等变体 |

| 边界 | 处理 |
| :--- | :--- |
| 项目不存在与无权限 | 显示同一文案，不区分，避免探测项目是否存在 |
| 接口越权 | 服务端拒绝，响应不含该项目任何业务数据（AC-F01-05、NFR-003） |
| 页面标题 | 浏览器标题为「无权访问 · 君华装修项目管理平台」，不带项目名 |
