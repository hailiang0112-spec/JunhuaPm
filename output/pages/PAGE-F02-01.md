## 2. 页面概述

- **定位**：让已受邀开通账号的成员用手机号和密码进入平台。
- **存在理由**：签认、放行都要落在本人身上（US-F02-02），必须有可靠的身份门禁。
- **不做什么**：
  - 不做注册入口：账号只能通过邀请链接开通（REQ-F02-01，由 PAGE-F02-02 承接）。
  - 不做短信验证码、找回密码、第三方登录：上游只确认了邀请制 + 手机号密码（蓝图 §3）。忘记密码只提示联系公司管理员重置（REQ-F02-03）。
  - 不做「记住我」等登录态时效选项：时效固定为 7 天无操作失效（AC-F02-05）。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 全部已开通账号的成员：业主、业主代理人、项目经理、设计经理、质检、预算专员、公司管理员 |
| 设备 | 手机（现场、微信内置浏览器）与电脑 |

- **场景 A 正常登录**：输入手机号和密码 → 登录成功 → 进入我的待办。
- **场景 B 输错密码**：提示「手机号或密码错误」，可重试；15 分钟内连续第 5 次输错后锁定 15 分钟，页面显示剩余锁定时间倒计时（AC-F02-06）。
- **场景 C 临时密码登录**：公司管理员重置密码后，成员用临时密码登录 → 直接进入个人设置页的强制改密态（AC-F02-07，由 PAGE-F02-03 承接）。
- **场景 D 登录过期**：7 天无操作后访问任一页面 → 回到本页，顶部提示「登录已过期，请重新登录」。

## 4. 信息架构

1. 品牌区：logo「君」+「君华装修项目管理平台」。
2. 登录卡：标题「登录」、过期提示（条件显示）、锁定提示（条件显示）、手机号、密码、登录按钮。
3. 辅助说明：「忘记密码请联系公司管理员重置」；「仅限受邀成员使用，没有账号请向项目经理或公司管理员索取邀请链接」。

## 5. 界面内容

| 元素 | 内容 / 文案 | 显示条件 |
| :--- | :--- | :--- |
| 手机号 | 输入框，`tel` 类型，11 位，占位「请输入手机号」 | 始终 |
| 密码 | 密码输入框，明文不回显 | 始终 |
| 登录按钮 | 「登录」；提交中为「登录中…」不可重复点击；锁定时为「已锁定 mm:ss」不可点击 | 始终 |
| 过期提示 | 「登录已过期，请重新登录」 | 从失效登录态重定向而来 |
| 锁定提示 | 「该账号已锁定：15 分钟内连续 5 次密码错误。请在 mm:ss 后重试。」倒计时每秒刷新，归零后自动解除 | 账号处于锁定期 |
| 忘记密码提示 | 「忘记密码请联系公司管理员重置」（纯文字，不是链接） | 始终 |

## 6. 交互流程

```
输入手机号、密码 → 点「登录」（电脑端可按 Enter）
  ├─ 手机号为空 / 不是 11 位 → 字段旁提示，不发起请求
  ├─ 密码为空 → 字段旁提示，不发起请求
  └─ 提交校验
       ├─ 账号处于锁定期 → 显示锁定提示与剩余时间，不校验密码
       ├─ 手机号或密码错误 → 「手机号或密码错误」(DEC-101)；15 分钟内第 5 次 → 进入锁定态
       ├─ 临时密码正确 → 进入 PAGE-F02-03（强制改密态）
       └─ 正确 → 进入 PAGE-F16-01 我的待办
```

- 登录成功后的落点：进入「我的待办」首页，同屏列出本人有角色的工地（AC-F02-05 rev2，已由 rev2 需求覆盖；原 rev1 写「项目列表」与蓝图 §1 的分歧已由 RA-018 消除）。「我的工地」卡片按成员身份过滤（AC-F01-04）。

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 初始态 | 打开页面 | 手机号框聚焦 |
| 过期态 | 登录态 7 天无操作后失效被重定向 | 卡片顶部提示「登录已过期，请重新登录」 |
| 提交态 | 点击登录后 | 按钮「登录中…」，禁止重复提交 |
| 失败态 | 凭据错误 | 密码框下方「手机号或密码错误」，清空密码框 |
| 锁定态 | 15 分钟内连续 5 次错误 | 锁定提示 + mm:ss 倒计时；输入框与按钮不可用；倒计时结束恢复初始态 |
| 网络错误 | 请求失败 | 「网络异常，请检查网络后重试」，可直接重试 |

- 本页无空数据与无权限状态（门禁页本身不读业务数据）。

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 手机号必填 | 提交时 | 非空 | 请输入手机号 |
| 手机号格式 | 提交时 | 11 位数字，以 1 开头 | 请输入 11 位手机号 |
| 密码必填 | 提交时 | 非空 | 请输入密码 |
| 身份校验 | 服务端 | 手机号 + 密码 | 手机号或密码错误（DEC-101） |
| 锁定 | 服务端 | 同一手机号 15 分钟内连续 5 次错误 → 锁定 15 分钟（AC-F02-06） | 锁定提示 + 剩余时间 |

- **DEC-101（design-derived）**：失败文案统一为「手机号或密码错误」，不区分账号不存在与密码错误，也不显示剩余可试次数，避免通过登录页探测手机号是否已开通。
- 密码以加盐慢哈希存储，任何界面和日志都不显示明文（NFR-006）；本页不提供「显示密码」。
- 登录态 7 天无操作失效（AC-F02-05）。

```
直接访问 / 登录过期重定向 / 退出登录
            │
            ▼
      登录页 PAGE-F02-01
   ┌────────┼─────────────┐

   │        │             └→ 留在本页倒计时
   ▼        ▼

```

## 10. 数据需求

| 数据 | 方向 | 用途 |
| :--- | :--- | :--- |
| 手机号、密码 | 提交 | 身份校验 |
| 锁定剩余秒数 | 读取 | 锁定倒计时 |
| 是否临时密码 | 读取 | 决定落点为待办还是强制改密 |

明确排除：注册信息、验证码、第三方授权。
