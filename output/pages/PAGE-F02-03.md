# 页面名称：个人设置页

## 1. 文档元信息

| 字段 | 内容 |
| :--- | :--- |
| 页面 ID | `PAGE-F02-03` |
| Source IDs | `REQ-F02-03, REQ-F02-04, AC-F02-07, AC-F02-08`；design-derived: `DEC-104, DEC-105` |
| 功能范围 | 查看个人信息、修改密码；临时密码登录后强制改密，改密前不能做其他操作 |
| 所属产品 | 君华装修项目管理平台 |
| 所属模块 | 账号 |
| 适用端 | 响应式网页 |
| 页面路由 | `/me`（强制改密：`/me?force=1`） |
| 页面类型 | 表单 |
| 所属阶段 | 全量交付 |
| 上游来源 | 左侧导航底部「个人设置」/ 手机「更多」；PAGE-F02-01 · 登录页（临时密码登录） |
| 下游去向 | PAGE-F16-01 · 我的待办（强制改密完成后）；PAGE-F02-01 · 登录页（退出登录） |

## 2. 页面概述

- **定位**：成员查看自己的账号信息并修改密码；临时密码登录的成员在这里先设新密码。
- **存在理由**：管理员重置后的临时密码只能用一次（AC-F02-07）；成员也要能自己换密码并让其他设备下线（AC-F02-08）。
- **不做什么**：不改手机号、不改姓名（需求未提供）；不做找回密码。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 所有已登录成员 |
| 设备 | 手机与电脑 |

- **场景 A 主动改密**：输入原密码、新密码、确认新密码 → 保存 → 提示「密码已修改，其他设备上的登录已失效」。
- **场景 B 强制改密**：公司管理员在 PAGE-F01-02 重置密码 → 成员用临时密码登录 → 自动进入本页强制改密态，导航不可用 → 设新密码 → 进入我的待办。

## 4. 信息架构

1. 外壳：左侧导航 / 手机底部标签，工地切换器显示「全部工地」。强制改密态下导航不可用。
2. 强制改密横幅（条件显示）。
3. 个人信息卡：姓名、手机号（本人完整号码）、账号开通日期、我的项目与角色。
4. 修改密码卡。
5. 退出登录（DEC-105）。

## 5. 界面内容

**个人信息**（只读）

| 字段 | 示例 |
| :--- | :--- |
| 姓名 | 王工 |
| 手机号 | 186 0211 3390（本人可见完整号码） |
| 账号开通 | 2026-09-08 |
| 我的项目与角色 | 君华新城 · 联排别墅装修工程 — 质检；滨江壹号 · 独栋别墅 — 质检 |

**修改密码**

| 字段 | 必填 | 规则 | 强制改密态 |
| :--- | :--- | :--- | :--- |
| 原密码 | 是 | 与当前密码一致 | 隐藏（DEC-104） |
| 新密码 | 是 | ≥ 8 位，含字母和数字（NFR-006） | 显示 |
| 确认新密码 | 是 | 与新密码一致 | 显示 |
| 按钮 | — | 「保存新密码」 | 「设置新密码并继续」 |

**强制改密横幅**：「你正在使用临时密码登录，请先设置新密码。设置完成前不能进行其他操作。」

## 6. 交互流程

```
主动改密：填写 → 保存
  ├─ 校验失败 → 字段旁提示
  └─ 成功 → 更新密码，其他设备登录态全部失效 → 提示「密码已修改，其他设备上的登录已失效」，当前设备保持登录

强制改密：临时密码登录 → 本页（force）
  ├─ 点击导航 / 底部标签 → 不跳转，提示「请先设置新密码」
  └─ 设置成功 → 临时密码作废 → 进入 PAGE-F16-01
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常态 | 普通登录 | 个人信息 + 修改密码 |
| 强制改密态 | 临时密码登录 | 横幅 + 隐藏原密码 + 导航不可用 |
| 加载态 | 读取个人信息 | 信息卡骨架屏 |
| 错误态 | 读取失败 | 「个人信息加载失败（网络中断），请重试」+ 重试 |
| 提交失败 | 原密码错误 / 规则不符 | 字段旁提示，表单内容保留（密码框清空） |

- 本页只读本人数据，没有空数据与无权限状态。

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 原密码 | 服务端 | 与当前密码一致 | 原密码不正确 |
| 新密码规则 | 提交时 | ≥ 8 位，含字母和数字 | 密码至少 8 位，需同时包含字母和数字 |
| 确认一致 | 提交时 | 与新密码一致 | 两次输入的新密码不一致 |

- 修改成功后该账号其他设备上的登录态全部失效（AC-F02-08）。
- 临时密码一次性；用临时密码登录后必须先设置新密码才能进行其他操作（AC-F02-07），服务端同样拦截其他请求（NFR-003）。
- **DEC-104（design-derived）**：强制改密时不再要求输入原密码（登录时已校验临时密码），只填新密码两次。
- **DEC-105（design-derived）**：本页提供「退出登录」，用于共用电脑或交接手机后主动下线。

## 9. 页面流转

```
导航「个人设置」 ──→ 本页 ──→ 退出登录 → PAGE-F02-01
PAGE-F02-01（临时密码）──→ 本页（强制）──→ 设置成功 → PAGE-F16-01
```

## 10. 数据需求

| 数据 | 方向 | 用途 |
| :--- | :--- | :--- |
| 姓名、手机号、开通日期、项目与角色 | 读取 | 个人信息 |
| 是否临时密码 | 读取 | 强制改密态 |
| 原密码、新密码 | 提交 | 修改密码 |

## 11. 验收标准

| 编号 | 验收点 | 通过标准 | 来源 |
| :--- | :--- | :--- | :--- |
| F-01 | 修改密码 | 原密码正确 + 新密码合规 → 更新成功，其他设备登录失效 | AC-F02-08 |
| F-02 | 原密码错误 | 提示「原密码不正确」，密码不变 | AC-F02-08 |
| F-03 | 强制改密 | 临时密码登录后只能停留本页，设新密码前点击导航不跳转 | AC-F02-07 |

| S-01 | 密码规则 | 不满足 8 位且含字母和数字时拒绝；任何位置不显示明文 | NFR-006 |
| U-01 | 手机可用 | 375px 宽无横向滚动 | NFR-001 |
