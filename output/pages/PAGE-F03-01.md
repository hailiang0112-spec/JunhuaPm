## 2. 页面概述

- **定位**：公司管理员维护「开新工地时复制什么」：工段、楼层、房间、工作项、检查点模板，以及按名称自动补齐工作说明和验收标准的工序说明库。
- **存在理由**：新工地不用从零录入上百项工作（US-F03-01）；同类工序在不同房间共用一套说明（REQ-F03-05）。
- **不做什么**：
  - 不改动已创建项目：模板保存只影响之后新建的项目（AC-F03-01）。
  - 检查点模板不含图纸位置：图纸位置只能在项目里对着签认版图纸钉点（DEC-113）。
  - 不做 Excel 导入：Excel 导入导出属于项目（PAGE-F03-03）。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 公司管理员（周经理）；其他角色无权访问 |
| 设备 | 电脑为主；手机可查看和小改 |

- **场景 A 调整工序规则**：质检反馈门洞经常偏差 → 周经理把「门洞」规则的验收标准补上「净宽偏差 ±10mm」，并上移到「隔墙」通用规则之前 → 保存模板 → 之后新建的项目生效，君华新城不受影响。
- **场景 B 增加检查点模板**：在「隔墙砌筑」工作项下增加检查点模板「拉结筋每 500mm 一道」，勾选「隐蔽」。

## 4. 信息架构

1. 外壳：工地切换器「全部工地」，导航「公司模板」高亮。
2. 顶栏：标题、模板选择（君华联排别墅标准模板 / 君华独栋别墅模板）、主按钮「保存模板」。
3. 生效说明条：「保存后只对之后新建的项目生效，已创建的 4 个项目不变。最近保存：2026-10-12 16:20 周经理」。
4. 规模概览：6 个工段 · 6 层 32 个房间 · 187 项工作 · 71 条工序规则。
5. 四个标签页：工段 / 楼层与房间 / 工作项与检查点 / 工序说明库。

## 6. 交互流程

```
切换模板 → 加载该模板（有未保存修改时先拦截确认「放弃未保存的修改？」）
任一标签页内编辑 → 顶栏显示「有未保存的修改」
点「保存模板」→ 校验 → 保存 → 提示「模板已保存，只对之后新建的项目生效」（AC-F03-01）

工序规则：上移 / 下移 → 序号即时变化（保存模板后生效）
          删除 → 简单确认「删除规则 #5 给水、打压？」→ 移除
          编辑 → 弹窗（关键词*、工作说明*、验收标准*）
```

- **AC-F03-10 的补齐行为**发生在项目里新建或导入工作项时（PAGE-F03-02、PAGE-F03-03）；本页的「工作项与检查点」标签对模板工作项展示同样的补齐结果预览：说明为空的工作项显示「将由工序规则 #n 补齐」，帮助管理员检查规则顺序。

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常态 | 有模板 | 四个标签页 |
| 加载态 | 读取模板 | 概览与表格骨架屏 |
| 空状态 | 某标签无数据（如新模板无工序规则） | 「还没有工序规则。添加第一条规则，新建工作项时会自动补齐说明。」+ 添加规则 |
| 错误态 | 读取 / 保存失败 | 「模板保存失败（网络中断），修改仍保留在页面上，可重试」 |
| 无权限态 | 非公司管理员 | 「仅公司管理员可访问公司管理页面」+ 返回我的待办（DEC-108） |

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 工段名称 | 保存时 | 非空、不重名 | 请填写工段名称 / 工段名称重复 |
| 工段权重合计 | 保存时 | = 100% | 工段权重合计为 96%，需为 100% |
| 工作项名称 | 保存时 | 非空 | 请填写工作项名称 |
| 工作项楼层 | 保存时 | 必选；房间必须属于该楼层（级联选择） | 请选择楼层 |
| 工作项权重 | 保存时 | 1–5 整数 | 权重为 1–5 的整数 |
| 检查要点 | 保存时 | 非空 | 请填写检查要点 |
| 规则关键词 / 说明 / 标准 | 保存时 | 非空 | 请填写匹配关键词 等 |

- 模板修改只影响之后新建的项目，已创建项目的结构与内容不变（AC-F03-01）。
- 工序规则按顺序匹配，首个命中补齐空缺字段，已填写字段不覆盖（AC-F03-10）。
- **DEC-112（design-derived）**：原型用正则表达式匹配，公司管理员不便维护。本设计以「匹配关键词」录入，工作项名称包含任一关键词即命中；顺序用上移 / 下移维护。
- **DEC-113（design-derived）**：检查点模板挂在模板工作项下，只含检查要点与是否隐蔽；图纸分册、版本与坐标在项目内对签认版图纸钉点时确定（AC-F06-01）。
