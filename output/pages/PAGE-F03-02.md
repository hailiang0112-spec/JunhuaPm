## 2. 页面概述

### 2.1 一句话定位
项目经理把从模板复制来的结构改成与真实房屋、真实计划一致。

### 2.2 存在理由
1. 模板（6 工段、6 层、32 房间、187 项）与每套房子不完全一致，需要增删改（AC-F03-02）。
2. 已有签认、核对、问题或资料的结构若被删除，证据链会断，只能停用（AC-F03-03）。
3. 工作项的楼层与房间必须匹配，否则矩阵与筛选会错位（AC-F03-04）。

### 2.3 不做什么
- 不改公司模板（PAGE-F03-01）。
- 工段计划起止、班组、权重、范围在工段详情编辑并自动留档，本页不提供这些字段的编辑（DEC-315）。
- 工作项基线（图纸版本、费用、检查点）在 PAGE-F05-01 维护。

## 3. 用户与场景
| 维度 | 描述 |
| :--- | :--- |
| 角色 | 项目经理（编辑）；其他成员只读 |
| 使用设备 | 电脑 |

**场景 A：新增房间与工作项**：业主把负一楼影音室改成储藏，项目经理停用「影音室」，新增「储藏室 3」并添加工作项。
**场景 B：误删防护**：项目经理删除「负一楼 · 车库」→ 系统提示「已有记录，只能停用」→ 确认停用。

## 4. 信息架构
1. 顶栏：标题、来源模板说明、演示身份、「Excel 导入导出」、「新增工作项」
2. 只读提示（非项目经理）
3. 页签：楼层与房间（启用楼层数 / 房间数）｜工段（数量）｜工作项（启用数）
4. 楼层与房间：楼层表 ｜ 所选楼层的房间表
5. 工段：工段表
6. 工作项：筛选工具栏 + 工作项表 + 分页

## 5. 界面内容

### 5.1 楼层表 / 房间表
- 楼层列：楼层、启用房间数、关联记录、状态（启用 / 已停用印章）、改名、删除。点行切换右侧房间表。
- 房间列：房间、工作项数、关联记录、状态、改名、删除。已停用房间注明「历史记录仍可在问题与审计中查看」。
- 关联记录 = 签认、核对、问题、资料记录数之和。

### 5.2 工段表（AC-F03-05、AC-F03-06）
工段（工段色点）、计划起止、权重、工作项数、加权进度条（Σ(wi×pi)÷Σwi，1 位小数，无工作项 0%）、状态（自动推导，不可编辑）、关联记录、编辑计划（→ PAGE-F10-03）、改名、删除。

### 5.3 工作项表
- 筛选：工段、楼层、名称搜索、「显示已停用」。
- 列：工作项、工段、楼层 / 房间（全楼通用 / 本层通用）、计划日期、负责人、权重、完成度、关联记录、状态、编辑 / 删除（项目经理）或查看（其他角色）。
- 分页每页 20 条。

### 5.4 工作项表单
| 字段 | 必填 | 规则 / 反馈 |
| :--- | :--- | :--- |
| 工作项名称 | 是 | 「请填写工作项名称」 |
| 所属工段 | 是 | 只列启用工段 |
| 负责人 | 否 | 空则记为「待指派」 |
| 楼层 | 是 | 只列启用楼层 + 全楼通用 |
| 房间 | 是 | 列该楼层启用房间 + 本层通用；不匹配时「房间与楼层不匹配」（AC-F03-04） |
| 计划日期 | 否 | 日期 |
| 权重 | 是 | 1–5 整数，「权重为 1–5 的整数」 |
| 完成度 | 是 | 0–100 整数，「完成度为 0–100 的整数」 |
| 工作说明 / 验收标准 | 否 | 文本 |

楼层改变后，原已选房间若不属于新楼层，保留在下拉中并标注「（不属于所选楼层）」，提交时拒绝（DEC-309）。编辑有关联记录的工作项时提示「已签认的基线内容需走变更单修改」。

### 5.5 新增 / 改名弹窗
名称（必填、同级不重名）；新增房间时选所属楼层。

### 5.6 删除 / 停用弹窗（AC-F03-02、AC-F03-03，DEC-308）
- 无关联记录：确认摘要（对象、关联记录 0 条、删除后从矩阵与筛选项移除）→「确认删除」。
- 有关联记录（楼层、工段还包括下级房间或工作项）：红色提示「已有记录，只能停用」+ 摘要（对象、关联条数、停用后不再出现在新增选项中且历史可查、停用不可撤回）→「确认停用」。

## 6. 交互流程

```
点删除 ─┬─ 关联记录 = 0 → 确认摘要 → 删除 → 矩阵、筛选项即时更新，提示
        └─ 关联记录 > 0 → 「已有记录，只能停用」 → 确认停用 → 状态变「已停用」，新增选项中消失
保存工作项 → 逐字段校验 → 失败：字段旁红字 → 成功：工段进度重新计算，提示
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载 | 进入 | 表格骨架屏 |
| 空 | 楼层下无房间 / 筛选无结果 | 「该楼层还没有房间。」/「没有符合条件的工作项。」 |
| 只读 | 非项目经理 | 顶部只读提示；所有新增、改名、删除、编辑按钮隐藏 |
| 错误 | 保存失败 | 弹窗内提示原因，输入保留 |
| 无权限 | 非项目成员 | PAGE-F01-03 |

| 边界 | 处理 |
| :--- | :--- |
| 同名 | 同一楼层下房间、同级楼层或工段重名时拒绝「已存在同名…」 |
| 停用的楼层下仍有房间 | 房间随楼层不再出现在新增选项 |
| 已停用项 | 不再提供改名、删除；历史记录保持可查 |

## 10. 数据需求
- 读取：楼层、房间、工段、工作项及各自关联记录数与停用状态。
- 提交：新增 / 改名 / 删除 / 停用（对象、名称、所属楼层）；工作项（字段见 5.4）。

## 11. 验收标准

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 增删改无记录结构 | 新增、改名、删除没有关联记录的楼层、房间、工段后，矩阵与筛选项即时反映（AC-F03-02） |
| F-02 | 有记录只能停用 | 删除有签认、核对、问题或资料记录的结构被拒并提示「已有记录，只能停用」；停用后不出现在新增选项，历史可查（AC-F03-03） |
| F-03 | 楼层房间匹配 | 房间不属于所选楼层时拒绝保存并提示「房间与楼层不匹配」（AC-F03-04） |
| F-04 | 加权进度 | 工段表进度 = Σ(wi×pi)÷Σwi，权重 1–5、完成度 0–100 整数（AC-F03-05） |
| F-05 | 状态自动 | 工段状态按进度推导，无手改入口（AC-F03-06） |
| F-06 | 只读角色 | 业主等角色看不到任何编辑按钮 |

## 12. 设计补充（design-derived）

| 编号 | 内容 |
| :--- | :--- |
| DEC-308 | 删除前一律显示确认摘要；有记录时提示「已有记录，只能停用」并提供停用确认；停用不可撤回（上游未定义重新启用） |
