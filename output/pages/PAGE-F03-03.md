## 2. 页面概述

### 2.1 一句话定位
用 Excel 整批维护计划，用原型备份把砌墙阶段已录的数据迁过来，且不碰已签认的基线。

### 2.2 存在理由
1. 187 项工作逐条录入成本高，项目经理习惯原型的 Excel 表（AC-F03-07）。
2. 导入若覆盖已签认基线，等于绕过签认（AC-F03-09）。
3. 砌墙阶段在原型里已有数据，不能丢（REQ-F18-01）。

### 2.3 不做什么
- 不导出证据包或审计日志（PAGE-F17-01）。
- 原型导入不生成任何签认、核对或放行记录（AC-F18-01）。

## 3. 用户与场景
| 维度 | 描述 |
| :--- | :--- |
| 角色 | 项目经理（Excel）；公司管理员（原型备份） |
| 使用设备 | 电脑 |

**场景 A：整批更新计划**：导出当前计划 → 在 Excel 中细化水电工作项 → 上传 → 看到第 27 行「书房 B 不属于三楼」等 5 处错误 → 改好重传 → 校验通过 → 确认导入 → 结果中 3 项「已签认，需走变更单」，点「发起变更单」。
**场景 B：迁移原型数据**：公司管理员在项目为「筹备」时上传原型 JSON → 导入成功，3 个文件只有元数据，标记「文件缺失，需重新上传」。

## 4. 信息架构
1. 顶栏：标题、说明、演示身份
2. Excel 计划模板与导出：下载空白模板、导出当前计划、五张工作表说明
3. 上传计划文件：选择文件区、当前文件条、校验结果（错误清单或通过摘要 + 执行导入）
4. 导入结果：最近一次导入的统计与已签认项清单
5. 原型 v1.20 备份导入：项目状态门槛说明、上传区（仅筹备项目）、导入记录
6. 页内无权限状态

## 5. 界面内容

### 5.1 模板与导出（AC-F03-07）
- 「下载空白模板」「导出当前计划」均生成 .xlsx。
- 五张工作表：施工阶段、工作事项、补充事项、填写说明、取值；数值列为数字格式，日期列为文本格式（页面以说明文字展示）。

### 5.2 上传与逐行校验（AC-F03-08）
- 接受 .xlsx、.csv；其他格式提示「只支持 .xlsx 或 .csv 计划文件，请重新选择」。
- 按表头识别列。文件条显示文件名、上传人与时间、识别的工作表数与行数。
- 有错误：红色横幅「发现 N 处错误。全部修正前不能执行导入…」+ 错误表（工作表、行号、列、问题），不显示「执行导入」。错误类别：阶段名不可识别、楼层与房间不匹配、日期无法识别、权重越界（1–5）、完成度越界（0–100）。
- 全部通过：绿色横幅 + 统计（新增工作项、更新未签认工作项、已签认（不修改）、与当前一致）+「执行导入」。

### 5.3 确认导入（DEC-310）
确认摘要：文件、新增 N 项、更新 N 项未签认、已签认 N 项不修改并在结果中列出、施工阶段表是否引起计划变化 →「确认导入」。

### 5.4 导入结果（AC-F03-09）
最近一次导入：文件、印章「已导入」、统计（新增、更新、已签认需走变更单、错误行 0）；已签认工作项表：工作项、文件中的修改、处理印章「已签认，需走变更单」、「发起变更单」（→ PAGE-F07-02 预填该工作项）。

### 5.5 原型备份导入（AC-F18-01 ~ AC-F18-03，DEC-311）
- 门槛：仅「筹备」状态项目可上传。当前项目非筹备时显示「当前项目状态为「施工中」。原型备份只能导入「筹备」状态的项目…」，不显示上传区。筹备项目对公司管理员显示 .json 上传区。
- 导入记录（倒序）：
  - 成功：印章「已导入」、文件名、时间与操作人、项目当时状态；各类计数：工作事项、问题、人工出勤登记、计划变更留档、补充事项、公告留言、验收图片；说明「每条均标注来源「原型导入」；未生成任何签认、核对或放行记录」。
  - 文件缺失：红色提示「N 个资料文件只有元数据、没有文件本体，已标记「文件缺失，需重新上传」」及清单（文件名、所属工作项或档案位置、「去补传」）。
  - 拒绝：印章「已拒绝」、文件名、「不是有效的原型备份文件。项目数据未改变。」

## 6. 交互流程

```
选择文件 ─┬─ 格式不是 xlsx/csv → 提示重新选择
          └─ 校验 ─┬─ 有错误 → 错误清单（工作表 + 行号），不能导入
                   └─ 通过 → 统计 + 执行导入 → 确认摘要 → 导入
                         → 仅新增新工作项、更新未签认工作项；已签认项不改
                         → 结果卡列出「已签认，需走变更单」，提示条汇总
原型备份（筹备项目、公司管理员）→ 上传 JSON
          ├─ 不可解析 → 「不是有效的原型备份文件」，项目数据不变
          └─ 可解析 → 导入七类内容并标注「原型导入」，缺本体文件标记「文件缺失，需重新上传」
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 初始 | 未上传 | 只有选择文件区；导入结果卡显示上次结果或「还没有导入记录」 |
| 校验中 | 上传后 | 文件条 + 骨架行 |
| 校验失败 | 有错误行 | 错误清单，无导入按钮 |
| 校验通过 | 无错误 | 统计 + 执行导入 |
| 导入中 | 确认后 | 按钮禁用，完成后结果卡刷新 |
| 原型门槛 | 项目非筹备 | 状态说明，无上传区，仅导入记录 |
| 无权限 | 非项目经理 / 公司管理员 | 页内「当前身份不能使用数据导入导出」+ 返回项目总览 |

## 11. 验收标准

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 模板与导出 | 生成 .xlsx，含五张工作表，数值列数字格式、日期列文本格式（AC-F03-07） |
| F-02 | 逐行校验 | 五类错误都列出工作表与行号；有错误时无法执行导入（AC-F03-08） |
| F-03 | 不覆盖签认 | 只新增新工作项、更新未签认项；已签认项不改并逐项列为「已签认，需走变更单」（AC-F03-09） |
| F-04 | 原型导入 | 七类内容导入并标注「原型导入」，不生成签认、核对、放行（AC-F18-01） |
| F-05 | 文件缺失 | 只有元数据的文件标记「文件缺失，需重新上传」（AC-F18-02） |
| F-06 | 格式错误 | 非原型备份提示「不是有效的原型备份文件」，项目数据不变（AC-F18-03） |
| F-07 | 筹备门槛 | 非筹备项目不显示原型上传区 |

## 12. 设计补充（design-derived）

| 编号 | 内容 |
| :--- | :--- |
| DEC-310 | 计划文件校验通过后先显示确认摘要再导入；结果中已签认项提供「发起变更单」入口（PAGE-F07-02） |
| DEC-311 | 原型备份以导入记录列表展示成功 / 拒绝 / 文件缺失清单；项目非「筹备」时不显示上传区并说明原因 |
| DEC-312 | 数据导入导出页按角色分区：项目经理看 Excel 区与原型导入记录，公司管理员只看原型导入区，其他角色显示页内无权限状态 |
