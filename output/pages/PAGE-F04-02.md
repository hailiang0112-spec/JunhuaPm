## 2. 页面概述

### 2.1 一句话定位
在现场看清「这项活该按哪一版图做」，并能把任意两版并排看出改了什么。

### 2.2 存在理由
1. 现场按错版本施工是「图纸与现场不一致」的直接来源，需要明确显示所用版本号（AC-F04-08）。
2. 改了十版的图，只有并排对比加改动说明才能讲清每次改了什么（AC-F04-05）。
3. 检查点钉在图上，才能把照片与图纸位置对应起来。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 版本清晰 | 打开即显示版本号与签认状态；工作项待重签时 100% 显示横幅 |
| 对比可用 | 任选两版并排显示，并列出两版之间所有版本的改动说明 |
| 手机可用 | 375px 下页面无横向滚动，图纸在自身区域内缩放和拖动 |

### 2.4 不做什么
- **不做**版本删除、替换或编辑改动说明（AC-F04-04）。
- **不做**图纸签认与上传：在 PAGE-F04-01。
- **不做**新建或移动钉点：钉点在 PAGE-F05-01 新建检查点时点选。
- **不做**自动比对像素差异：Source IDs 只要求并排显示与改动说明。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 本项目全部成员（只读） |
| 使用设备 | 手机（现场看图）、电脑（对比） |

**场景 A：从工作项打开看图** — 显示该工作项基线引用的签认版与版本号；若该分册已有更新的签认版且工作项待重签，图上方显示「图纸已更新，基线待重签」（AC-F04-08）。
**场景 B：对比两版** — 点「两版并排对比」→ 选左右版本 → 看两版图与期间所有改动说明（AC-F04-05）。
**场景 C：从钉点进入检查点** — 点钉点 → 侧栏摘要 → 打开检查点。

## 4. 信息架构
1. 面包屑（图纸 › 分册 › 查看器）+ 标题（分册 · 楼层）+ 来源说明（从哪个工作项打开、基线引用版本、当前签认版）+ 演示身份
2. 待重签横幅（条件显示）
3. 控制条：版本选择、缩放（缩小 / 百分比 / 放大 / 适应宽度）、钉点图层开关、两版并排对比
4. 单版视图：版本印章与文件信息、「已发布版本只读，不可删除或替换」、图纸区、钉点图例；右侧（手机为下方）钉点详情
5. 对比视图：左右两版图纸各带版本选择；下方「两版之间的改动说明」

## 5. 界面内容

### 5.1 元素清单

**版本选择**：列出该分册全部版本，标注状态：「V1 · 已签认 · 本工作项基线引用」「V2 · 已签认 · 当前签认版」「V3 · 待业主签认」。从工作项打开时默认选中基线引用版本（AC-F04-08）。

**版本信息行**：印章（已签认 `pass` / 待签认 `pend`）+「V2 · 水电点位图-V2.pdf（6.8MB）· 刘先生 2026-10-16 签认」；待签认版补充「不能作为基线或钉点底图」（AC-F05-02、AC-F06-01）。

**图纸区**：PDF 或图片渲染；缩放 50%–300%，每次 25%；图纸在自身区域内滚动、鼠标拖动平移、手机双指缩放（DEC-209）。

**钉点图层**（DEC-209）：显示绑定在当前所看版本上的检查点；颜色按状态：未核对（灰）、待放行（橙）、不一致（红）、已放行（绿）、代理放行（青）；带图例；可关闭。

**钉点详情**：点击钉点后显示编号、名称、状态印章、位置（楼层 · 房间 · 是否隐蔽）、情况（如「结论一致（核对 #2）· 已等 30 小时，超时」）、「打开检查点」→ PAGE-F06-02。

**待重签横幅**：「图纸已更新，基线待重签。本工作项基线引用 V1；水电点位图 V2 已于 2026-10-16 签认。重签前现场仍按 V1 施工与核对。」+「查看工作项」。

**对比视图**：左、右版本下拉；两版图纸并排（手机上下排列）；改动说明列表：范围「V1 → V3 · 共 2 版」，逐版列出版本号、状态、改动说明、发布人与时间、签认人与时间、受影响工作项数。选同一版本时提示「请选择两个不同的版本」。

## 6. 交互流程
- 加载：按来源参数确定分册、版本、工作项；判断横幅条件。
- 切换版本 → 刷新图纸、印章、文件信息与钉点。
- 缩放 / 拖动 / 图层开关 → 只影响图纸区。
- 点「两版并排对比」→ 进入对比视图（按钮变「退出对比」），默认左为基线引用版、右为最新版。

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载 | 打开或切换版本 | 图纸区骨架屏 |
| 待签认版本 | 选中待业主签认的版本 | 印章「待签认」，无钉点，提示不可作基线 |
| 无钉点 | 该版本无检查点 | 钉点详情显示「该版本尚无检查点钉点」 |
| 文件加载失败 | 图纸文件读取失败 | 图纸区「图纸加载失败，请重试」+ 重试 |
| 无权限 | 非本项目成员 | 跳转 PAGE-F01-03 |

边界：任何角色在本页都没有删除、替换版本的入口；接口层同样拒绝（AC-F04-04、NFR-003）。

## 8. 业务规则
- 显示版本以工作项基线引用为准，不自动切到最新版（AC-F04-08）。
- 横幅条件：分册存在比基线引用更新的签认版，且该工作项基线状态为待重签（AC-F04-08）。
- 改动说明范围：较早版本（不含）到较晚版本（含）之间的全部版本（AC-F04-05）。
