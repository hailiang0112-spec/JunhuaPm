## 2. 页面概述

### 2.1 一句话定位
把一项工作的「按哪版图、怎么做、多少钱、何时完、谁来查、查哪里」写成基线交业主签认，并承载它的检查点、资料和修订历史。

### 2.2 存在理由
1. 基线是开工前签认的对象，字段缺一项日后就说不清（AC-F05-01）。
2. 签认后必须锁定，修订只能走变更单或新版图纸重签，否则签认失去意义（AC-F05-06）。
3. 检查点要在开工前钉在签认图上，盖住前才有对照位置（AC-F06-01）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 基线完整 | 提交的基线 100% 含 7 项必填（AC-F05-01） |
| 引用合规 | 0 个基线引用未签认图纸版本（AC-F05-02） |
| 锁定有效 | 已签认字段 0 次被直接修改（AC-F05-06） |

### 2.4 不做什么
- **不做**签认与退回：在 PAGE-F05-02（业主）。
- **不做**核对与放行：在 PAGE-F06-02。
- **不做**工作项的楼层、房间、权重等结构编辑：在 PAGE-F03-02。
- **不做**资料物理删除：只能作废（AC-F12-03）。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 项目经理（编辑基线、提交、进度、新建检查点）；预算专员（提交前填写费用，PRD §2.1）；质检（新建检查点）；业主等只读；业主方成员只读（AC-F01-12）；公司管理员对业务数据只读，看不到编辑、提交、新建检查点按钮（AC-F01-13）；全体成员可上传资料（业主方成员只读，不显示上传） |
| 使用设备 | 电脑编辑为主，手机查看 |

**场景 A：准备并提交基线（草稿 / 已退回）** — 填写 7 项 → 至少 1 个检查点 → 提交待签。
**场景 B：已签认后尝试修改** — 点锁定字段 → 提示「已签认，请发起变更单或等待新版图纸重签」；进度仍可改（AC-F05-06）。
**场景 C：新版图纸签认后重签（示例页面状态）** — 横幅提示待重签 → 「更新图纸版本并重新提交」→ 选已签认的新版本 → 提交 → 业主重签后引用新版、旧签认记录保留（AC-F05-08，DEC-206）。
**场景 D：新建检查点** — 填要点、选是否隐蔽、在签认版图纸上点选位置，可从已审核经验中加入要点（AC-F06-01、AC-F09-04）。基线为「已签认」或「待重签」时，保存前显示确认摘要，确认后检查点**立即生效**，基线签认状态不变，修订与签认历史追加一条「新增检查点」记录，并向业主生成「新增检查点」知会待办；新检查点保存后与已有检查点一样不可修改或删除（AC-F06-16）。
**场景 F：待签认期间尝试修改（示例：重签稿提交后）** — 点锁定字段或「新建检查点」→ 提示「基线待业主签认，需业主退回后才能修改」，不打开编辑（AC-F05-10、DEC-211）。
**场景 E：上传与作废资料** — 一次多选上传；不合格文件单独列出原因；上传者作废自己的文件（AC-F12-01–03）。

## 4. 信息架构
1. 面包屑（工段 › 楼层 › 房间）+ 标题 + 「资料 N」按钮 + 演示身份
2. 状态横幅（待重签 / 已退回理由 / 即将施工未签认，按状态显示）
3. 左列：基线卡（状态印章、当前生效修订、7 项字段及锁定标识）→ 检查点卡 → 修订与签认历史
4. 右列：进度卡（完成度、实际完成日期）→ 资料卡
5. 弹窗：基线编辑（提交 / 重签）、新建检查点、图片放大

## 5. 界面内容

### 5.1 基线卡
- 状态印章：草稿（普通标签）/ 待签认 `pend` / 已签认 `pass` / 待重签 `pend` / 已退回（红色普通标签）。
- 「当前生效 r2 · 2026-10-14」。
- 字段：图纸分册与版本、工作说明、验收标准、费用（元）、计划完成日期、质检人、检查点数。
- 已签认 / 待重签 / 待签认时每个字段带锁形按钮（项目经理、预算专员可见）。已签认、待重签时点击提示「已签认，请发起变更单或等待新版图纸重签」（AC-F05-06）；待签认时点击提示「基线待业主签认，需业主退回后才能修改」（AC-F05-10）。
- 底注：「已签认内容锁定，修订只能通过变更单或新版图纸重签；进度字段不受影响。」

### 5.2 基线编辑弹窗（草稿、已退回、待重签时可用）
- 签认版图纸分册与版本（必填）：列出分册全部版本并标状态；选「待业主签认」版本时立即提示「该版本尚未签认」并清空（AC-F05-02）。
- 工作说明、验收标准、费用（元）、计划完成日期、质检人（均必填）。
- 检查点（至少 1 个）：列表，可从「新建检查点」加入。
- 提交：缺项时列出全部缺失字段「以下字段缺失，无法提交：…」（AC-F05-01）。
- 待重签时标题为「更新基线并提交重签」，预填当前生效内容，图纸版本需重新选择（DEC-206）。

### 5.3 检查点卡
- 每行：编号、名称、是否隐蔽与当前情况、一个状态印章（DEC-201，如「超时」「不得覆盖」）；整行进入 PAGE-F06-02。
- 「新建检查点」（项目经理、质检）。基线待签认时点击只提示「基线待业主签认，需业主退回后才能修改」（AC-F05-10、DEC-211）。
- 直接生效的新检查点行显示「已生效 · 已知会业主」（AC-F06-16）。

### 5.4 新建检查点弹窗
- 检查要点（必填）、是否隐蔽（必填：是（未放行不得覆盖）/ 否）。
- 在图纸上点选位置（必填）：底图为基线引用的签认版，点击放置钉点，显示「底图：水电点位图 V1 · 二楼 · 坐标 (x, y)」（AC-F06-01）。
- 「砌墙工段经验推荐（已审核）」：按「已验证、历史观察、未验证经验」排序，每条「加入要点」将其检查要点加入（AC-F09-04）。
- 基线已签认或待重签时，提示「保存后立即生效，不改变基线签认状态，并通知业主；已有检查点仍不可修改或删除」。点「保存检查点」→ 确认摘要（工作项、检查要点、是否隐蔽、底图与坐标、生效方式「立即生效，基线保持『待重签 / 已签认』」、知会对象「业主 刘先生、陈女士」、「保存后不可修改或删除」）→ 确认 → 检查点生效、历史追加留痕、业主收到知会待办（AC-F06-16）。
- 基线为草稿或已退回时，新检查点进入基线编辑稿，随基线一起提交签认（AC-F05-01 的「≥1 检查点」）。
- ~~基线已签认或待重签时，新检查点随重签稿一并提交业主签认（DEC-210）~~ —— 已作废，见 §12。

### 5.5 修订与签认历史（只追加）
示例（倒序）：2026-10-16 水电点位图 V2 签认，本项受影响 → 待重签；2026-10-14 变更单 BG-001 生效，追加修订 r2（新增 2 个插座底盒，费用 1,280 → 1,640 元，链接 PAGE-F07-02）（AC-F07-04）；2026-10-08 刘先生签认 r1（水电点位图 V1）· 含完整内容快照；2026-10-06 张工提交基线待签。

### 5.6 进度卡
完成度（%）、实际完成日期、「保存进度」（项目经理）；签认锁定不影响这两项（AC-F05-06）。

### 5.7 资料卡
- 上传（多选）：图片、PDF、Word、Excel，单个 ≤ 50MB。
- 结果：「已上传 N 个文件」；不合格文件列出「文件名：原因」，同批合格文件照常上传（AC-F12-02）。
- 列表：图片显示缩略图可放大；其他文件「下载」；上传人、时间、大小；被引用的标注「被核对 #2 引用」。
- 「作废」：仅上传者本人可见；被核对、签认或变更单引用的文件提示「被…引用，不能作废」；作废需确认摘要，作废后默认隐藏，可勾选「显示已作废（N）」查看作废人与时间（AC-F12-03）。
- 标题区「资料 N」显示未作废文件数（AC-F12-01）。

## 6. 交互流程

```
提交 / 重签基线
  ├─ 选择待签认图纸版本 → 「该版本尚未签认」（AC-F05-02）
  ├─ 缺字段 → 列出全部缺失字段（AC-F05-01）
  └─ 通过 → 状态「待签认」，进入 PAGE-F05-02 业主待签列表（重签项标「重签」）
        └─ 业主签认 → 「已签认」，引用新版本，旧签认记录保留（AC-F05-08）
已签认后修改锁定字段 → 拒绝并提示（AC-F05-06）
变更单生效 → 追加修订，不覆盖原签认记录（AC-F07-04）
新版图纸签认且本项被勾选 → 「待重签」；重签前核对按原签认版（AC-F05-07）
已签认 / 待重签时新建检查点 → 确认摘要 → 立即生效，签认状态不变，追加留痕，业主收到「新增检查点」知会待办（AC-F06-16）
待签认时修改锁定字段或新建检查点 → 拒绝并提示「基线待业主签认，需业主退回后才能修改」（AC-F05-10、DEC-211）
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 草稿 | 新建未提交 | 字段可编辑，「提交待签」 |
| 待签认 | 已提交 | 字段只读，横幅「等待业主签认」；锁形按钮与「新建检查点」点击提示「基线待业主签认，需业主退回后才能修改」（AC-F05-10） |
| 已签认 | 业主签认 | 字段锁定，进度可改 |
| 待重签 | 受影响新版图纸被签认 | 横幅「基线待重签……」+「对比 V1 / V2」+「更新图纸版本并重新提交」 |
| 已退回 | 业主退回 | 横幅显示退回理由，字段可编辑后再提交 |
| 加载 / 错误 | 读取中 / 失败 | 骨架屏 / 「加载失败，请重试」 |
| 资料为空 | 无文件 | 「还没有资料。」+ 上传 |
| 检查点为空 | 无检查点 | 「还没有检查点。先在工作项基线里添加检查点。」 |
| 无权限 | 非本项目成员 | 跳转 PAGE-F01-03 |

边界：作废被引用文件被拒（AC-F12-03）；超限文件不影响同批其他文件（AC-F12-02）；业主等只读角色看不到编辑、提交、新建检查点按钮。

| F-08 | 多文件上传（AC-F12-01） | 多选上传全部保存，资料按钮显示数量，图片可放大，其他文件可下载 |
| F-09 | 超限拒绝（AC-F12-02） | 超 50MB 或格式不符的文件显示文件名与原因，同批其他文件正常上传 |
| F-10 | 作废留痕（AC-F12-03） | 上传者作废后默认隐藏并记录作废人与时间；被引用文件不能作废 |
| F-11 | 修订历史（AC-F07-04） | 变更单生效时追加引用该变更单的修订，原签认记录不变 |

| F-13 | 待签认锁定（AC-F05-10） | 基线待签认时，点锁定字段或「新建检查点」均提示「基线待业主签认，需业主退回后才能修改」，不进入编辑 |
| F-14 | 只读角色（AC-F01-12、AC-F01-13） | 业主方成员、公司管理员看不到编辑、提交、新建检查点、上传按钮 |
| U-01 | 印章唯一（DEC-201） | 基线卡与每个检查点行各只有一个印章 |

## 12. 设计决策

| 编号 | 状态 | 内容 |
| :--- | :--- | :--- |
