## 2. 页面概述

### 2.1 一句话定位
让现场人员一眼看到哪些隐蔽工序还不能盖、哪些在等放行、哪些出了问题。

### 2.2 存在理由
1. 「不得覆盖」必须在手机检查点列表中以红色标签显示（AC-F06-11），否则工人和项目经理不知道哪里不能动。
2. 超时与未放行先覆盖需要可见，才能推动业主及时放行、暴露流程缺失（AC-F06-12、AC-F06-13）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 可见性 | 100% 未放行的隐蔽检查点显示「不得覆盖」或更紧急的红色印章 |
| 定位效率 | 两次点击内筛到某工段或某楼层的待处理检查点 |
| 手机可用 | 375px 下页面无横向滚动（NFR-001） |

### 2.4 不做什么
- **不做**列表内直接核对或放行：不可撤回的操作只在 PAGE-F06-02 完成，需看证据。
- **不做**批量操作：蓝图 §5 规定只有基线签认支持批量。
- **不做**新建检查点：在 PAGE-F05-01 基线中完成。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 本项目全部成员（只读列表，入口一致） |
| 使用设备 | 手机为主，电脑查看 |

**场景 A：质检找待核对项** — 点「待核对」或「不得覆盖」筛选 → 选楼层 → 进入详情核对。
**场景 B：业主处理待放行** — 点「待放行」或「超时」→ 进入详情放行。
**场景 C：项目经理查覆盖前风险** — 看「不得覆盖」与「未放行先覆盖」数量。

## 4. 信息架构
1. 标题区：「检查点」+ 项目、总数、放行时限 + 演示身份
2. 概况卡（4 个）：不得覆盖、待放行（含超时数）、不一致（含放行后发现数）、已放行（含代理放行数）
3. 列表卡：状态筛选 chips（带数量）、工段与楼层下拉、列表（电脑为表格、手机为卡片）、分页

## 5. 界面内容

### 5.1 元素清单

**状态筛选 chips**：全部 / 不得覆盖 / 待核对 / 待放行 / 超时 / 不一致 / 放行后发现不一致 / 未放行先覆盖 / 已放行；每个 chip 显示在当前工段、楼层条件下的数量。手机端 chips 横向滑动（页面本身不横向滚动）。

| 筛选 | 命中条件 |
| :--- | :--- |
| 不得覆盖 | 隐蔽、未放行、未覆盖（AC-F06-11） |
| 待核对 | 尚无核对记录 |
| 待放行 | 当前结论一致或已变更且未放行 |
| 超时 | 待放行超过项目时限（AC-F06-13） |
| 不一致 | 当前结论不一致且此前未放行 |
| 放行后发现不一致 | 已放行后追加不一致核对 |
| 未放行先覆盖 | 存在未放行先覆盖事件（AC-F06-12） |
| 已放行 | 有放行记录（含代理放行） |

**工段**：全部工段 + 本项目工段（砌墙、水电、铺砖、木工、油灰工、安装收尾）。
**楼层**：全部楼层 + 本项目楼层（负一楼、夹层、一楼、二楼、三楼、楼顶阳台）。

**列表行 / 卡片**
- 状态：一个印章（DEC-201 优先级：放行后发现不一致 > 不一致 > 未放行先覆盖 > 超时 > 不得覆盖 > 待放行 > 已放行 / 代理放行）；非隐蔽且未核对显示普通标签「待核对」。
- 编号（如 CK-031）、检查点名称、楼层 · 房间、工段（工段色点）、是否隐蔽。
- 当前情况一句话：如「实测 860mm · 王工 2026-10-26 15:42 · 覆盖前 · 问题 WT-024」「结论一致 · 待放行已等 30 小时（时限 24 小时）」「刘太太 2026-10-22 代理放行」。
- 整行可点击进入 PAGE-F06-02。

**分页**：每页 20 条（蓝图 §5），显示「共 N 条 · 每页 20 条」。

## 6. 交互流程
- 加载：默认「全部」，按紧急程度排序（DEC-202：与印章优先级同序，同级按进入该状态的时间早者在前）。
- 点 chip / 改下拉 → 即时过滤，chip 数量随工段、楼层条件更新。
- 点行 / 卡片 → PAGE-F06-02。
- 无结果 → 空状态「没有符合筛选条件的检查点。」+「清除筛选」。

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载 | 进入页面 | 概况卡与列表骨架屏 |
| 空（项目无检查点） | 尚无检查点 | 「还没有检查点。先在工作项基线里添加检查点。」+ 进入工段详情 PAGE-F10-03 |
| 空（筛选无结果） | 条件过严 | 「没有符合筛选条件的检查点。」+ 清除筛选 |
| 错误 | 读取失败 | 「加载失败，请重试」+ 重试 |
| 无权限 | 非本项目成员 | 跳转 PAGE-F01-03 |

## 8. 业务规则
- 隐蔽检查点未放行时以红色印章显示，不因其他筛选被隐藏颜色（AC-F06-11）。
- 超时只标记，不改变放行状态（AC-F06-13）。
- 数量与列表只统计本项目检查点（REQ-F01-03）。

## 9. 页面流转
```
导航「检查点」/ 手机标签「检查点」→ 本页 → 点行 → PAGE-F06-02 检查点详情·核对与放行
```

| 数据 | 用途 |
