## 2. 页面概述

### 2.1 一句话定位
让项目成员看清本项目全部变更单走到了哪一步，并让项目经理从这里发起新变更单。

### 2.2 存在理由
1. 变更先签后做：没有统一台账，口头变更无从追溯，事后对不上费用和承担方。
2. 后补变更需要单独识别，才能看出「先签后做」做得怎么样。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 找得到 | 任一状态的变更单 1 次筛选可见 |
| 发起快 | 项目经理 1 次点击进入发起表单 |

### 2.4 不做什么
- 不在列表上定价、签认或驳回——这些操作在 PAGE-F07-02 完成，带二次确认。
- 不统计「变更先签后做比例」——该指标属于 PAGE-F10-01。
- 不批量操作——蓝图 §5 只允许基线签认批量。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 项目经理（发起）；预算专员（找待预算定价）；业主（找待签认）；其他成员只读 |
| 使用设备 | 手机 / 电脑 |

**场景 A：项目经理发起变更**：现场需要调整 → 点「发起变更单」→ 进入 PAGE-F07-02 发起表单。
**场景 B：业主找待签认的变更单**：筛选「待签认」→ 点行进入详情签认。

## 4. 信息架构
1. 顶栏：标题、副标题、演示身份、主操作「发起变更单」（仅项目经理）。
2. 变更单卡片：状态筛选 chips + 关键字搜索；列表（电脑为表格，手机为卡片）；分页。

## 5. 界面内容

### 5.1 元素清单

**状态筛选 chips**：全部 / 待预算定价 / 待签认（对应状态「待业主签认」）/ 已生效 / 已驳回 / 后补变更。「后补变更」按标记筛选，与状态独立（REQ-F07-01，后补标记来自 AC-F07-08 的发起字段）。

**搜索框**：按编号或变更内容模糊匹配。

**列表字段**

| 字段 | 内容 | 示例 |
| :--- | :--- | :--- |
| 编号 | 项目内序号（AC-F07-02） | BG-003 |
| 变更内容 | 标题 + 标签「后补变更」「需新版图纸」；已驳回的单另带「待项目经理修改后重新提交」（AC-F07-09） | 一楼厨房烟道预留位调整（纠正偏移 120mm） |
| 原因类别 | 业主要求 / 设计深化 / 现场条件 / 施工纠偏 | 设计深化 |
| 受影响工作项 | 数量 | 3 |
| 费用增减（元） | 正数带 +，负数带 −；未定价显示「待预算定价」 | +1,800 |
| 工期影响（天） | 可为 0 或负数；未定价显示 — | +1 |
| 承担方 | 业主 / 装修公司 / 设计方；未定价显示 — | 设计方 |
| 状态 | 印章：待预算定价、待业主签认（橙）、已生效（绿）、已驳回（红） | 待业主签认 |
| 发起 | 发起人 + 日期 | 张工 2026-10-24 |

排序：编号倒序（最新在上）。分页每页 20 条。

**发起变更单按钮**：仅项目经理可见（US-F07-01），链接 `PAGE-F07-02.html?new=1`。

### 5.2 辅助信息
- 计数标签「共 N 张」随筛选变化。

## 6. 交互流程

### 6.1 页面加载
加载本项目全部变更单，默认「全部」，按编号倒序。

### 6.2 核心操作
```
点状态 chip / 输入关键字 → 列表即时过滤 → 无结果显示「没有符合条件的变更单」
点某行（手机点卡片） → PAGE-F07-02?id=编号
项目经理点「发起变更单」 → PAGE-F07-02?new=1
```

## 7. 状态与边界

### 7.1 页面状态

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 有变更单 | 列表 + 分页 |
| 空 | 项目还没有变更单 | 「还没有变更单」+ 说明；项目经理可见「发起变更单」 |
| 筛选无结果 | 筛选后为 0 | 「没有符合条件的变更单」 |
| 加载 | 请求中 | 骨架屏 |
| 错误 | 网络中断 | 「变更单加载失败（网络中断）」+ 重新加载 |
| 无权限 | 访问未受邀项目 | 跳转 PAGE-F01-03 无权限页 |

### 7.2 边界
| 场景 | 处理 |
| :--- | :--- |
| 非项目经理 | 不显示「发起变更单」（无权限按钮隐藏，蓝图 §3） |
| 手机端 | 卡片列表，页面无横向滚动 |

## 8. 业务规则
- 编号为「项目内序号」，状态初始为「待预算定价」（AC-F07-02）；状态流转见 PAGE-F07-02。
- 已驳回不是终止删除，记录永久保留（关键记录只追加）。项目经理可在 PAGE-F07-02 修改后重新提交，编号不变、回到「待预算定价」，列表中该行状态随之变化，驳回历史在详情页保留（AC-F07-09）。

## 9. 页面流转
```
导航 / 待办 / 总览 ──→ 变更单列表（本页）──┬─ 点行 ──→ PAGE-F07-02 变更单详情
                                         └─ 发起 ──→ PAGE-F07-02 发起表单
```
