## 2. 页面概述

### 2.1 一句话定位
让业主进入工地后一眼看清进度偏差、问题遗留和证据链是否按规矩在走。

### 2.2 存在理由
1. 没有总览，业主只能逐个工段翻看，看不到总体滞后多少（AC-F10-01）。
2. 四项证据链指标是本期成功度量（PRD §6），没有固定位置展示就无法评估「发现时点前移」。
3. 原型 v1.20 的总览模块是用户已有习惯，必须全部保留（AC-F10-03）。

### 2.3 页面目标
| 目标维度 | 具体指标 |
| :--- | :--- |
| 口径正确 | 完成度、计划基准、工期、四项指标与 AC 公式逐项一致，保留 1 位小数 |
| 一屏判断 | 电脑端首屏可见 KPI 六卡与证据链四项指标 |
| 不虚报 | 分母为 0 时显示「暂无数据」；出勤未登记不推算 |

### 2.4 不做什么
- 不在本页编辑任何数据：问题的登记、闭环在 PAGE-F08-01，工段计划在 PAGE-F10-03（DEC-301）。
- 不提供证据包导出与操作日志（属于 PAGE-F17-01）。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 业主（主要）、业主代理人、项目经理、设计经理、质检、预算专员；公司管理员只读 |
| 使用设备 | 电脑为主，手机查看 |

**场景 A：业主周末看进度（主场景）**：打开总览 → 看总体完成度与计划基准差值 → 看四项指标是否低于目标线 → 点低于目标的指标卡查看对应记录。
**场景 B：项目经理周会**：按工段筛选指标，看问题遗留清单的超期排序，导出计划变更留档 CSV 附在周报里。

## 5. 界面内容

### 5.1 KPI 六卡（AC-F10-01、AC-F10-02）
| 卡片 | 主数值 | 辅助信息 |
| :--- | :--- | :--- |
| 总体完成度 | Σ(工段权重×工段进度)÷Σ工段权重，1 位小数 | 计划基准 = Σ(工段权重×工段计划进度)÷Σ工段权重；「领先 / 滞后 X 个百分点」，滞后为红色标签 |
| 工期进度 | 已用天数 ÷ 总工期 | 项目周期 S ~ E（各工段最早开始、最晚结束）；总工期 = E−S+1；已用 = 今天−S+1，限制在 0 到总工期 |
| 今日出勤 | 今天各工段出勤之和；无登记显示「未登记」（DEC-303） | 在施工段数、累计人·日 |
| 发现问题 | 问题总数（不含已作废） | 超期未闭环数 |
| 已闭环 | 已闭环数 | 闭环率 |
| 问题遗留 | 处理中 + 未闭环 | 分别计数 |

示例：总体完成度 2.8%，计划基准 6.1%，滞后 3.3 个百分点；周期 2026-09-19 ~ 2027-08-30，已用 39 天 / 总 346 天。

### 5.2 证据链四项指标（AC-F10-04 ~ AC-F10-08）
- 筛选：全项目、砌墙、水电、铺砖、木工、油灰工、安装收尾（单选 chips，默认全项目）。
- 每张卡：指标名、百分比（M÷N，1 位小数）、「M / N + 单位」说明、进度条与目标线刻度、达标状态标签。

| 指标 | 分子 M | 分母 N | 目标线 |
| :--- | :--- | :--- | :--- |
| 覆盖前发现比例 | 发现时点为「覆盖前」的不一致记录 | 未作废的不一致记录 | 90%（标注针对水电阶段） |
| 隐蔽检查点合规率 | 覆盖前同时具备签认版核对、≥1 张照片和放行记录的 | 已放行或已覆盖的隐蔽检查点 | 100% |
| 最新签认版使用率 | 所用图纸为核对当时该分册最新签认版的核对记录 | 核对记录 | 100% |
| 变更先签后做比例 | 未标记后补的已生效变更单 | 已生效变更单 | 100% |

- N = 0：数值位显示「暂无数据」与「分母为 0」，不显示 0% 或 100%，进度条只保留目标线（AC-F10-08）。示例：筛选「水电」时三项为暂无数据，最新签认版使用率 1/1 = 100.0%。
- 低于目标显示「低于目标 X 个百分点」（橙），达到显示「达到目标」（绿）。
- 点卡片进入对应记录列表（DEC-302）。

### 5.3 六阶段甘特图（AC-F10-03）
每工段一行：浅色条为计划区间，深色条为实际完成度占比，右侧「35.2%（计划 76.0%）」；月份刻度；红色虚线为今天。点工段名进入 PAGE-F10-03。

### 5.4 楼层 × 阶段矩阵（AC-F10-03）
行：负一楼、夹层、一楼、二楼、三楼、楼顶阳台、全楼通用；列：六工段。单元格为该楼层在该工段的加权完成度，7 档色阶：0% 未开始、1–39%、40–69%、70–89%、90–99%、100% 完成、无事项。点行名 → PAGE-F10-02 打开该楼层详情抽屉；点单元格 → PAGE-F10-03 并筛选该楼层。

### 5.5 房间短板 TOP 8 / 房间问题 TOP 6
- 短板：按跨工段加权完成度升序取 8 个房间，列楼层/房间、事项数、完成度条、问题数（有遗留标红）。
- 问题：按问题数降序取前 6 个有问题的房间，列问题、闭环、遗留、闭环率；不足 6 个时注明「其余房间暂无问题记录」。
- 点行 → PAGE-F10-02 打开该房间详情。

### 5.6 每日出勤日历（AC-F11-04、AC-F11-03）
按月展示（上月 / 下月，限项目周期内）。每格为当日各工段出勤之和，五档着色：0、1–4、5–8、9–12、13 及以上；今天加描边。没有任何登记的过去日期显示「未登记」，按 0 计，不推算；未来日期留空。顶部显示该月合计人·日、施工天数、峰值（含日期），以及未登记天数（DEC-303）。

### 5.7 问题发现与闭环 · 按阶段
每工段一根堆叠柱：已闭环（绿）、处理中（橙）、未闭环（红），顶部为总数；不含已作废。点柱 → 该工段详情的问题区。

### 5.8 问题遗留清单（AC-F08-04）
未闭环与处理中问题，按超期天数从大到小排序；列：编号、阶段、楼层/房间、问题、等级、状态印章、负责人、要求闭环日期、超期天数（今天−要求闭环日，红色；未超期显示「—」）。点行 → PAGE-F08-01 问题详情。

### 5.9 计划变更台账（REQ-F14-02）
全工段留档，最新在前；列：记录时间、工段、变更项、变更前 → 变更后、工期影响（天）、原因备注；顶部「累计 N 条」与「导出 CSV」。CSV 列：记录时间、工段、变更项、变更前、变更后、工期影响（天）、变更原因备注（与 AC-F14-04 一致）。

### 5.10 各工段速览卡
每工段一卡：工段色点、名称、状态（自动）、进度条、工期、计划基准、累计出勤、峰值 / 施工天数、工作项数、问题与闭环数。点卡 → PAGE-F10-03。

## 6. 交互流程

```
进入总览 → 加载项目汇总
  ├─ 点指标筛选 chip → 四张指标卡按所选范围重算（分母 0 → 暂无数据）
  ├─ 点指标卡 → 对应记录列表
  ├─ 点矩阵单元格 / 甘特行 / 柱形 / 速览卡 → PAGE-F10-03（带工段与楼层筛选）
  ├─ 点楼层名 / 房间行 → PAGE-F10-02（自动打开详情抽屉）
  ├─ 上月 / 下月 → 出勤日历切换（超出项目周期时提示）
  ├─ 导出 CSV → 下载计划变更留档
  └─ 登记问题 → PAGE-F08-01 登记表单（DEC-301）
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载 | 首次进入 | KPI、指标卡与图表区显示骨架屏 |
| 正常 | 数据返回 | 如上各模块 |
| 空（筹备中项目） | 尚无工作项进度、问题、出勤 | KPI 显示 0.0%；指标卡全部「暂无数据」；遗留清单显示「当前无遗留问题」；台账显示「暂无计划变更留档」 |
| 局部空 | 某模块无数据 | 该模块内显示一句说明，不隐藏模块 |
| 错误 | 汇总加载失败 | 模块内显示「加载失败，请重试」与重试按钮，已加载模块保持 |
| 无权限 | 非本项目成员访问 | 跳转 PAGE-F01-03「无权访问该项目」 |

| 边界 | 处理 |
| :--- | :--- |
| 工段内无工作项 | 工段进度 0%（AC-F03-05），矩阵对应格为「无事项」 |
| 今天早于项目开始 | 已用天数 0；晚于结束则等于总工期 |
| 出勤未登记 | 显示「未登记」，按 0 计入合计，不生成推算人数 |

## 8. 角色差异（DEC-316）
- 所有项目成员可查看全部模块、导出 CSV。
- 「登记问题」对业主、业主代理人、项目经理、设计经理、质检、预算专员显示；公司管理员隐藏（不是项目成员）。
- 无权限操作隐藏，不置灰。
