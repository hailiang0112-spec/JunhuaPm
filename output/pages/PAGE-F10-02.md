## 2. 页面概述

### 2.1 一句话定位
按「楼层 × 房间 × 工段」三级定位，让成员看清每个房间做到哪一步、问题集中在哪里。

### 2.2 存在理由
1. 别墅 6 层 32 个房间，业主习惯按房间验收，工段视角看不出某个房间的短板。
2. 从房间直接下钻到工段工作项，减少在工段页里手工筛选（AC-F10-09）。

### 2.3 不做什么
- 不在本页增删改楼层、房间（在 PAGE-F03-02）。
- 抽屉中的「登记问题」跳转问题页登记表单并预填楼层、房间，不另建表单（DEC-301）。

## 3. 用户与场景
| 维度 | 描述 |
| :--- | :--- |
| 角色 | 全部项目成员；公司管理员只读 |
| 使用设备 | 电脑看矩阵；手机在现场打开某房间详情 |

**场景 A：业主验房前查房间**：点「二楼 · 书房 B」→ 抽屉列出砌墙、水电、铺砖各 1 项及 2 条未闭环问题 → 在抽屉里登记新问题。
**场景 B：项目经理下钻**：在房间矩阵点「书房 B × 砌墙」→ 进入砌墙工段详情，工作项已筛选为书房 B（AC-F10-09）。

## 4. 信息架构
1. 顶栏：标题、说明、演示身份、「全楼通用事项」、「登记问题」
2. KPI 六卡：楼层 / 房间数、工作项（已完成、通用）、房间覆盖、进展最快房间、短板房间、问题集中房间
3. 楼层 × 阶段完成度矩阵
4. 房间 × 阶段完成度矩阵（按楼层分组）
5. 各房间完成度（按楼层分组的房间卡片）
6. 各楼层工作量分布 ｜ 各楼层问题分布
7. 房间问题分布表
8. 楼层明细表
9. 楼层 / 房间详情抽屉

## 5. 界面内容

### 5.1 两个矩阵
- 单元格为该楼层（或房间）在该工段的工作项加权完成度（Σ权重×完成度÷Σ权重），1 位小数。
- 7 档色阶：0% 未开始、1–39%、40–69%、70–89%、90–99%、100% 完成、该工段无此范围事项（显示「—」，不可点）。
- 点行名 → 打开对应详情抽屉；点有事项的单元格 → `PAGE-F10-03?phase=<工段>&room=<房间>`（楼层矩阵为 `&floor=`），工作项表已按该房间（楼层）筛选（AC-F10-09）。

### 5.2 各房间完成度
按楼层分组；每楼层标题显示房间数、楼层加权完成度与楼层说明；房间卡显示名称、跨工段完成度、进度条、工作项数、问题数、遗留数；有遗留问题的卡左侧红线。点卡打开房间抽屉。

### 5.3 楼层分布图
- 工作量：各楼层工作项权重合计，按工段色堆叠，末尾为合计。
- 问题：各楼层已闭环 / 处理中 / 未闭环堆叠，末尾为总数。

### 5.4 房间问题分布 / 楼层明细
- 房间问题分布：只列有问题的房间，列问题、已闭环、遗留（红）和问题摘要（编号 + 描述）。
- 楼层明细：房间数、工作项、已完成、加权完成度、问题、遗留。
- 行可点，打开对应抽屉。

### 5.5 详情抽屉（楼层 / 房间）
- 标题：「二楼 · 书房 B」或「负一楼」；副标题为楼层说明。
- 统计：加权完成度、工作项、已完成、遗留问题。
- 跨工段工作项：按工段分组，组头有「在工段中查看」（→ PAGE-F10-03 带筛选）；每项显示名称（→ PAGE-F05-01）、检查点印章（不得覆盖 / 不一致 / 已放行，至多 1 个）、所在房间（楼层抽屉时）、负责人、计划日期、状态与完成度。
- 问题：编号、描述、等级、状态印章、工段、负责人、要求闭环、超期天数、「查看问题」。
- 底部：「在此登记问题」（→ PAGE-F08-01，预填楼层与房间）、「在砌墙（进行中）中查看」。
- 关闭：关闭按钮、点遮罩、Esc；关闭后焦点回到触发元素。

## 6. 交互流程

```
进入页面 ─┬─ URL 带 ?room= → 自动打开该房间抽屉（DEC-313）
          ├─ URL 带 ?floor= → 自动打开该楼层抽屉
          └─ 否 → 正常浏览
点房间 / 楼层 → 抽屉 ─┬─ 点工作项 → PAGE-F05-01
                       ├─ 在工段中查看 → PAGE-F10-03（筛选该房间）
                       └─ 在此登记问题 → PAGE-F08-01 登记表单
点矩阵单元格 → PAGE-F10-03（筛选该房间 / 楼层）
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载 | 首次进入 | 矩阵与卡片区骨架屏 |
| 空 | 项目尚无楼层房间 | 显示「还没有楼层和房间，项目经理可在项目结构中添加」，项目经理看到「去项目结构」 |
| 抽屉空 | 该房间无工作项 / 无问题 | 分别显示「该范围暂无工作项…」「该范围暂无问题记录」 |
| 错误 | 加载失败 | 模块内显示失败原因与重试 |
| 无权限 | 非项目成员 | PAGE-F01-03 |
| URL 参数无效 | 房间已删除或不存在 | 不打开抽屉，正常显示页面 |

已停用的房间不出现在矩阵与卡片中，其历史问题仍在问题页可查（AC-F03-03 由 PAGE-F03-02 负责）。

## 8. 角色差异（DEC-316）
「登记问题」「在此登记问题」对项目成员显示，公司管理员隐藏；其余内容全员可见。
