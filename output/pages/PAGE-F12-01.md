## 2. 页面概述

### 2.1 一句话定位
把平面布局图、三维效果图和装修合同按分类集中存放，业主随时能查，资料不再散落在微信群。

### 2.2 存在理由
1. 资料散落在聊天记录里，交房后找不到（US-F12-02）。
2. 合同涉及金额和条款，必须只对相关角色开放（AC-F12-06）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 查找效率 | 业主 2 次点击内找到任一专区任一分类的文件 |
| 权限 | 设计经理、质检 100% 看不到合同专区 |

### 2.4 不做什么
- 不做工作项资料（在 PAGE-F05-01）和阶段验收图片（在 PAGE-F10-03）。
- 不物理删除文件，只作废（DEC-121）。
- 不在线编辑文件内容。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 业主（查看为主）；项目经理、公司管理员（管理分类）；设计经理（上传布局图、效果图）；预算专员（合同与报价） |
| 使用设备 | 手机 / 电脑 |

**场景 A：业主查看效果图**：切到「三维效果图」→ 选「一楼」→ 点图片放大。
**场景 B：项目经理整理分类**：新建「地下室车库」分类；删除空分类「夹层」。
**场景 C：预算专员上传报价**：在「装修合同 · 报价与变更」上传报价单。

## 4. 信息架构
1. 顶栏：标题、演示身份
2. 专区标签：平面布局图 / 三维效果图 / 装修合同（仅业主、项目经理、预算专员、公司管理员可见）
3. 左栏分类列表（手机为横向滚动 chips）+ 分类管理工具（新建、改名、删除）
4. 右栏：分类标题、文件数、「显示已作废」、「上传文件」；文件网格
5. 弹窗：上传文件、新建/改名分类、文件预览、移动到分类、作废与删除分类的确认摘要

## 5. 界面内容

### 5.1 默认分类（PRD §3.3.12）

| 专区 | 默认分类 |
| :--- | :--- |
| 平面布局图 | 负一楼、夹层、一楼、二楼、三楼、楼顶阳台 |
| 三维效果图 | 同上（按楼层） |
| 装修合同 | 主合同、补充协议、报价与变更、付款凭证 |

分类项显示名称与有效文件数（不含已作废）。

### 5.2 文件卡片
- 缩略区：图片显示缩略图「图片 · 点击放大」；其他文件显示类型（PDF / XLSX / DOCX）。点击打开预览。
- 文件名、大小 · 上传人 · 上传日期。
- 标签「被{记录}引用」（如「被变更单 BG-001 引用」）。
- 已作废文件：「已作废」灰色印章 + 作废人 · 时间；不显示操作。
- 操作：下载（所有可见者）；移动（公司管理员、项目经理，DEC-122）；作废（仅上传者本人，DEC-121）。

### 5.3 上传弹窗（DEC-121）
说明「上传到『{专区 · 分类}』。可一次选择多个图片、PDF、Word 或 Excel 文件，单个不超过 50MB；不合格的文件会被拒绝，同批其他文件照常上传。」；选择后逐个列出文件名、大小与结果（可上传 / 已拒绝：原因）；「上传合格文件」。

### 5.4 预览弹窗
大图或文档预览、所在专区与分类、大小、上传人和时间、引用情况；「下载原件」。

### 5.5 示例数据
平面布局图 · 一楼：一楼平面布局图-V3.pdf（李工 2026-10-15）、一楼厨房深化节点图.pdf（张工，被变更单 BG-003 引用）、一楼现场复尺记录.pdf（张工）；二楼含已作废的「二楼平面布局图-V3 草稿.pdf」；夹层、楼顶阳台为空分类。装修合同 · 主合同：君华新城联排别墅装修工程施工合同.pdf（周经理 2026-09-12）。

## 6. 交互流程

### 6.1 加载
默认打开「平面布局图」的第一个有文件分类；带 `zone` 参数时打开对应专区。

### 6.2 核心流程
```
新建 / 改名分类（公司管理员、项目经理）→ 填名称 → 校验 → 保存（AC-F12-05）
删除分类
  ├─ 非空 → 提示「分类『{名称}』下还有 N 个文件，请先移出文件」（AC-F12-05）
  └─ 空 → 确认摘要 → 删除
上传 → 选择多个文件 → 逐个校验 → 合格的上传，不合格的列出文件名与原因
作废（上传者）
  ├─ 被关键记录引用 → 提示「该文件被{记录}引用，不能作废」
  └─ 否则 → 确认摘要 → 标记已作废，从默认列表隐藏，记录作废人与时间
设计经理 / 质检打开合同专区 → 「无权查看合同资料」（AC-F12-06）
```

## 7. 状态与边界

### 7.1 页面状态

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | — | 分类 + 文件网格 |
| 空分类 | 分类无有效文件 | 「这个分类还没有文件」+ 说明 |
| 加载 | 请求中 | 骨架屏 |
| 错误 | 网络中断 | 「资料加载失败（网络中断）」+ 重新加载 |
| 无权限（合同） | 设计经理、质检、业主代理人直达合同专区 | 「无权查看合同资料」+ 说明可查看角色 +「查看平面布局图」 |
| 无权限（项目） | 访问未受邀项目 | 跳转 PAGE-F01-03 |

### 7.2 边界

| 场景 | 处理 |
| :--- | :--- |
| 分类重名 | 「已有同名分类」 |
| 单个文件 > 50MB 或格式不允许 | 拒绝该文件并显示原因，同批其他文件照常上传 |
| 已作废文件 | 勾选「显示已作废」后可见，不可再操作 |

## 8. 业务规则与校验

| 规则 | 说明 | 来源 |
| :--- | :--- | :--- |
| 分类管理权限 | 公司管理员、项目经理可新建、改名、删除 | AC-F12-05 |
| 删除仅限空分类 | 非空分类提示先移出文件 | AC-F12-05 |
| 合同专区可见角色 | 业主、项目经理、预算专员、公司管理员；设计经理、质检拒绝访问并提示「无权查看合同资料」；业主代理人不在开放名单内（PRD §2.1） | AC-F12-06 |
| 上传与作废 | 沿用工作项资料规则：单个 ≤ 50MB，允许图片、PDF、Word、Excel；删除改为作废并留痕；被核对、签认或变更单引用的文件不能作废 | DEC-121（依据 PRD §3.3.12 关键边界、AC-F12-02/03 口径） |

**设计补充**
- **DEC-121（design-derived）**：档案上传与作废沿用 AC-F12-02、AC-F12-03 的限制；能查看该专区的成员均可上传（业主代理人除外，其只有放行权限）；作废仅限上传者本人。
- **DEC-122（design-derived）**：公司管理员、项目经理可把文件「移动到」同专区其他分类，用于满足「先移出文件」后删除分类。
