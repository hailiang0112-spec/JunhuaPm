## 2. 页面概述

### 2.1 一句话定位
把口头约定、增项和待办登记成台账，约定有据可查；涉及费用或做法的转为变更单。

### 2.2 存在理由
1. 口头约定事后对不上（US-F13-01）。
2. 涉及费用或做法的事项若不进入变更单，就绕过了业主签认。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 未完成可见 | 未完成事项 100% 排在已完成之前 |
| 转变更 | 项目经理 1 次点击生成预填草稿 |

### 2.4 不做什么
- 补充事项本身不定价、不签认——费用与签认走变更单。
- 不删除补充事项。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 所有项目成员（登记、切换状态）；项目经理（转为变更单） |
| 使用设备 | 手机 / 电脑 |

**场景 A：登记口头约定**：业主现场提出「三楼露台加装户外洗手池」→ 项目经理登记 → 待处理。
**场景 B：转为变更单**：该事项涉及费用 → 项目经理点「转为变更单」→ PAGE-F07-02 预填草稿。

## 4. 信息架构
1. 顶栏：标题、演示身份、主操作「登记补充事项」
2. 台账卡：计数（未完成 N、已完成 N）、排序说明；事项列表；空/加载/错误态
3. 登记弹窗

## 5. 界面内容

### 5.1 事项条目

| 元素 | 内容 |
| :--- | :--- |
| 编号 | BC-nnn |
| 标题 + 状态印章 | 待处理 / 处理中（橙）、已完成（绿） |
| 说明 | 文本 |
| 提出日期、约定完成日期、责任人 | 元信息行 |
| 已转变更单 | 「已转变更单 BG-xxx」链接 PAGE-F07-02 |
| 附件 | 附件名标签，点击打开 |
| 状态切换 | 三段按钮：待处理 / 处理中 / 已完成 |
| 转为变更单 | 仅项目经理，且未关联变更单、未完成（DEC-132） |

排序：未完成在前（待处理、处理中），已完成在后；同组内按约定完成日期升序（AC-F13-01）。

### 5.2 登记弹窗（AC-F13-01，必填范围 DEC-131）

| 字段 | 必填 | 说明 |
| :--- | :--- | :--- |
| 标题 | 是 | — |
| 说明 | 否 | — |
| 提出日期 | 是 | 默认今天 |
| 约定完成日期 | 是 | 不得早于提出日期 |
| 责任人 | 是 | 项目成员 |
| 附件 | 否 | 可多个 |

### 5.3 示例数据
BC-008 三楼露台加装户外洗手池（待处理，张工，附件「露台洗手池位置示意.jpg」，可转变更单）；BC-005 一楼厨房烟道调整口头约定（处理中，已转 BG-003）；BC-007 二楼主卧衣帽间隔墙后移 300mm（已完成，已转 BG-001）。

## 6. 交互流程
```
登记 → 校验 → 保存为「待处理」→ 按排序插入
点状态按钮 → 保存新状态 → 重新排序（已完成移到后面）→ 提示条
项目经理点「转为变更单」→ 生成预填内容与附件的变更单草稿 → 打开 PAGE-F07-02 发起表单 → 补充事项显示关联编号（AC-F13-02）
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | — | 台账 |
| 空 | 无事项 | 「还没有补充事项」+ 说明 + 登记按钮 |
| 加载 | 请求中 | 骨架屏 |
| 错误 | 网络中断 | 「补充事项加载失败（网络中断）」+ 重新加载 |
| 无权限 | 访问未受邀项目 | 跳转 PAGE-F01-03 |

| 边界 | 处理 |
| :--- | :--- |
| 约定完成早于提出 | 「约定完成日期不能早于提出日期」 |
| 已关联变更单 | 不再显示「转为变更单」，只显示关联编号 |

## 8. 业务规则
- 状态在「待处理 → 处理中 → 已完成」之间切换，任一成员可切换（AC-F13-01）。
- 转为变更单仅项目经理（与发起变更单权限一致，US-F07-01）。
- **DEC-131（design-derived）**：标题、提出日期、约定完成日期、责任人必填；说明、附件可空；约定完成日期不得早于提出日期。
- **DEC-132（design-derived）**：已完成或已关联变更单的事项不显示「转为变更单」，避免重复生成。

## 9. 页面流转
```
导航 ──→ 补充事项（本页）──转为变更单──→ PAGE-F07-02?new=1&from=BC-xxx
                          └─已转编号──→ PAGE-F07-02?id=BG-xxx
```
