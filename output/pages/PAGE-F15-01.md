## 2. 页面概述

### 2.1 一句话定位
付款前让各方看清关联工段的证据链是否齐全：还有多少检查点未放行、多少不一致没闭环。

### 2.2 存在理由
1. 付了款再发现问题，业主失去约束手段（US-F15-01）。
2. 用户决定只提示不拦截（D-6），所以标记已付要二次确认并留痕。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 付款前可见 | 每个节点 100% 显示两项计数 |
| 风险确认 | 仍有未放行时 100% 弹出确认 |

### 2.4 不做什么
- 不拦截付款、不对接支付或财务系统。
- 已付不能改回未付（标记已付为不可撤回操作）。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 预算专员（录入、标记已付）；所有成员（查看） |
| 使用设备 | 电脑为主，业主多用手机查看 |

**场景 A：录入节点**：按合同录入「水电完工款」，关联「水电」工段。
**场景 B：标记已付**：砌墙完工款还有 5 个检查点未放行 → 确认弹窗「还有 5 个检查点未放行，确认标记已付？」→ 确认后已付并留痕。

## 4. 信息架构
1. 顶栏：标题、演示身份、主操作「录入付款节点」（预算专员）
2. 说明条：只提示不拦截
3. 节点卡：电脑表格、手机卡片
4. 录入弹窗、标记已付确认弹窗

## 5. 界面内容

### 5.1 节点字段

| 字段 | 内容 |
| :--- | :--- |
| 节点 | 名称 |
| 金额（元） | 千分位 |
| 计划日期 | YYYY-MM-DD |
| 关联工段 | 工段色点 + 名称，可多个 |
| 未放行检查点 | 关联工段内未放行的检查点数；> 0 为红色，链接 PAGE-F06-01 |
| 未闭环不一致 | 关联工段内未闭环的不一致问题数；> 0 为红色，链接 PAGE-F08-01 |
| 状态 | 印章：未付（橙）/ 已付（绿）；已付下方显示「赵会计 · 时间」，如确认时仍有未放行，追加「确认时未放行 N 个」 |
| 操作 | 「标记已付」：仅预算专员，仅未付节点 |

排序：按计划日期升序。

### 5.2 录入弹窗（AC-F15-01）

| 字段 | 必填 | 规则 |
| :--- | :--- | :--- |
| 节点名称 | 是 | — |
| 金额（元） | 是 | 大于 0 的整数 |
| 计划日期 | 是 | — |
| 关联工段 | 是 | 多选，至少 1 个 |

### 5.3 标记已付确认（AC-F15-03）
- 标题：有未放行时「还有 N 个检查点未放行，确认标记已付？」；否则「确认标记已付？」
- 摘要：付款节点、金额、关联工段、未放行检查点、未闭环不一致问题、标记后「状态改为『已付』并留痕，不可撤回」
- 有未放行时附提示「付款提示不拦截：仍可标记已付，本次确认会记入留痕。」
- 按钮：取消 / 确认标记已付

### 5.4 示例数据
开工预付款 380,400 元（砌墙，已付 2026-09-19）；砌墙完工款 126,800 元（2026-11-10，砌墙，未放行 5、未闭环不一致 4，未付）；水电完工款 253,600 元；泥瓦木作完工款 317,000 元（铺砖、木工）；油漆完工款 126,800 元；竣工尾款 63,400 元。

## 6. 交互流程
```
录入 → 校验 → 保存，状态「未付」（AC-F15-01）
查看 → 每个节点实时显示两项计数（AC-F15-02）
标记已付 → 确认弹窗
  ├─ 取消 → 不变
  └─ 确认 → 状态「已付」+ 留痕（操作人、时间、确认时的未放行数）+ 盖章动效（AC-F15-03）
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | — | 节点列表 |
| 空 | 无节点 | 「还没有付款节点」+ 说明；预算专员可见「录入付款节点」 |
| 加载 | 请求中 | 骨架屏 |
| 错误 | 网络中断 | 「付款节点加载失败（网络中断）」+ 重新加载 |
| 无权限 | 访问未受邀项目 | 跳转 PAGE-F01-03 |

| 边界 | 处理 |
| :--- | :--- |
| 未放行数为 0 | 仍弹出确认摘要（标记已付不可撤回，蓝图 §5），无警示提示 |
| 非预算专员 | 不显示录入与标记已付 |

## 8. 业务规则
- 计数口径：关联工段（多个时求和）内未放行的检查点、未闭环且由不一致生成的问题（AC-F15-02）。
- 只提示不拦截，确认后允许标记（D-6、AC-F15-03）。

## 9. 页面流转
```
导航 ──→ 付款节点（本页）──未放行数──→ PAGE-F06-01
                        └─不一致数──→ PAGE-F08-01
```
