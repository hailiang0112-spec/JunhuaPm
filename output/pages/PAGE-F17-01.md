## 2. 页面概述

### 2.1 一句话定位
让业主确认关键记录没被改过，并能按范围自主导出证据包。

### 2.2 存在理由
1. 证据由被监督方（装修公司）托管，业主需要独立验证手段（debate-log #4）。
2. 发生纠纷时，业主需要带走完整、可校验的证据。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 可验证 | 校验结果明确为「完整」或给出第一条不一致记录 |
| 可导出 | 业主按工段、楼层、房间、时间任一范围导出 ZIP |

### 2.4 不做什么
- 不提供任何修改或删除关键记录、日志的入口（AC-F17-01）。
- 不做证据包定时导出或外发。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 业主、公司管理员（校验、导出证据包、查看日志）；所有成员（导出计划留档 CSV） |
| 使用设备 | 电脑为主，手机可用 |

**场景 A：业主校验**：点「执行完整性校验」→ 显示「完整」与链尾摘要。
**场景 B：业主导出砌墙阶段证据**：选工段「砌墙」→ 导出 ZIP。
**场景 C：查谁改过问题**：日志按对象「WT-023」筛选。
**场景 D：项目经理导出计划留档 CSV**。

## 4. 信息架构
1. 顶栏：标题、演示身份
2. 关键记录说明条（所有角色）
3. 非业主方提示卡（项目经理、设计经理、质检、预算专员、业主代理人）
4. 完整性校验卡 + 导出证据包卡（业主、公司管理员）
5. 操作日志卡（业主、公司管理员）
6. 计划变更留档导出卡（所有成员）

## 5. 界面内容

### 5.1 关键记录说明（AC-F17-01、AC-F17-02）
「签认、核对、放行、变更单状态、图纸版本、问题状态变化和计划留档属于关键记录，只能追加，任何角色（含公司管理员）都不能修改或删除；更正只能追加新记录。每条关键记录都带包含上一条摘要的 SHA-256 串联摘要。」

### 5.2 完整性校验（AC-F17-03）
- 说明「逐条重算本项目全部关键记录的摘要链，确认记录没有被改动。」
- 结果区：
  - 完整：印章「完整」+「摘要链完整」；校验时间、已校验条数（如 1,284 条关键记录，全部一致）、链尾摘要（等宽字体）。
  - 不完整：印章「不完整」+「发现不一致」；校验时间、第一条不一致记录编号与时间（如 KR-000873 · 2026-10-12 14:36:08）、记录内容、说明「该记录重算的摘要与保存的摘要不符，其后的记录无法通过校验。」
- 按钮「执行完整性校验」，执行中显示「校验中…」与骨架。
- 原型专用「原型演示结果：完整 / 发现不一致」下拉，仅用于演示两种结果，不属于产品功能。

### 5.3 导出证据包（AC-F17-04）

| 范围字段 | 选项 |
| :--- | :--- |
| 工段 | 全部工段 / 6 个工段 |
| 楼层 | 全部楼层 / 各楼层 |
| 房间 | 全部房间 / 所选楼层的房间 |
| 时间范围 | 开始日期至结束日期（默认项目开工日至今天） |

ZIP 内容清单：记录清单（.xlsx）、照片原件、相关图纸版本文件、签认内容快照、摘要清单（含导出时的链尾摘要）。
按钮「导出证据包（ZIP）」；完成后提示「已生成 {文件名}（范围：…），浏览器开始下载。」

### 5.4 操作日志（AC-F17-06）
- 筛选：操作人（DEC-171）、对象类型（变更单 / 问题 / 检查点 / 核对记录 / 资料文件 / 工段计划 / 成员）、对象编号或名称、开始日期、结束日期。
- 列：时间、操作人（角色）、操作（新增 / 修改 / 作废 / 状态变更）、对象、变更前、变更后。
- 只读，标注「只读，不能修改或删除」；分页每页 20 条，按时间倒序。

### 5.5 计划变更留档导出（AC-F14-04）
- 显示留档条数与 CSV 列：记录时间、工段、变更项、变更前、变更后、工期影响（天）、变更原因备注。
- 按钮「导出 CSV」（所有成员）。

### 5.6 非业主方提示（AC-F17-05）
「仅业主和公司管理员可导出证据包；完整性校验和操作日志也只对业主和公司管理员开放。你可以在下方导出计划变更留档。」

## 6. 交互流程
```
执行完整性校验 → 逐条重算摘要链 → 完整：显示「完整」；否则显示第一条不一致记录编号和时间（AC-F17-03）
导出证据包 → 校验时间范围 → 生成 ZIP（所选范围内五类内容）→ 下载（AC-F17-04）
非业主方直接调用导出 → 拒绝并提示「仅业主和公司管理员可导出证据包」（AC-F17-05）
日志筛选 → 即时过滤（AC-F17-06）
导出 CSV → 生成并下载（AC-F14-04）
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | — | 各功能区 |
| 校验中 / 导出中 | 执行后 | 按钮禁用并显示进度文案 |
| 日志空 | 筛选无结果 | 「没有符合条件的日志」 |
| 加载 | 请求中 | 各卡骨架屏 |
| 错误 | 网络中断 | 卡内提示失败原因 + 重试，已选范围保留 |
| 无权限（功能区） | 非业主、非公司管理员 | 校验、证据包、日志区块整体不显示，显示 5.6 提示 |
| 无权限（项目） | 访问未受邀项目 | 跳转 PAGE-F01-03 |

| 边界 | 处理 |
| :--- | :--- |
| 开始日期晚于结束日期 | 「开始日期不能晚于结束日期」，不导出 |
| 范围内无记录 | 仍生成 ZIP，记录清单为空并包含链尾摘要 |

## 8. 业务规则
- 关键记录只追加（AC-F17-01）；每条带串联 SHA-256 摘要（AC-F17-02）。
- 校验与日志查看：业主、公司管理员（AC-F17-03、AC-F17-06）；证据包导出：业主、公司管理员（AC-F17-05，蓝图 §9）。
- 计划留档 CSV：所有成员（AC-F14-04）。
- **DEC-171（design-derived）**：操作日志在 AC-F17-06 要求的「时间、对象」筛选之外，增加「操作人」筛选。

## 9. 页面流转
