# 原型外壳约定（生成页面 HTML 时共用）

为保证 28 个页面外观一致，所有 `pages/*.html` 遵守以下约定。依据：设计决策蓝图 §2 与 §5，DESIGN.md 布局一节。

## 加载
```html
<link rel="stylesheet" href="../tokens.css">
<link rel="stylesheet" href="app.css">
```
页面特有的样式写在页内 `<style>` 中，只能使用 `var(--xxx)`，禁止出现 Hex 颜色。

## 工地内页面的外壳

- **电脑端**：`.app` 网格包含两部分。
  - 左侧 `<nav class="side">`：品牌块（`.brand`，logo 字「君」，名称「君华 · 项目管理」）+ 工地切换器（`.sitepick`，示例工地「君华新城 · 联排别墅」）+ 导航分组。
  - 右侧 `<main class="main">`：顶部 `.topbar` 放页面标题、副标题，右侧放主操作。
- **手机端**：底部 `<nav class="tabbar">` 放 4 个 `.tab`：待办 `PAGE-F16-01.html`、检查点 `PAGE-F06-01.html`、图纸 `PAGE-F04-01.html`、更多（弹出全部导航）。
- 当前页导航项加 `.on`。待办和检查点导航项可带 `.badge` 数字，示例：待办 7、检查点 5。

左侧导航分组与链接（相对同目录）：
- 我的待办 → PAGE-F16-01.html
- **总览**：项目总览 PAGE-F10-01.html · 楼层 / 房间 PAGE-F10-02.html
- **施工阶段**：砌墙 / 水电 / 铺砖 / 木工 / 油灰工 / 安装收尾，全部指向 PAGE-F10-03.html（可带 `?phase=p1` 至 `p6`），每项前加工段色点（`--phase-1` 至 `--phase-6`）
- **证据链**：图纸 PAGE-F04-01.html · 基线签认 PAGE-F05-02.html · 检查点 PAGE-F06-01.html · 变更单 PAGE-F07-01.html · 问题 PAGE-F08-01.html
- **房屋档案**：档案资料 PAGE-F12-01.html · 补充事项 PAGE-F13-01.html · 公告栏 PAGE-F13-02.html · 付款节点 PAGE-F15-01.html
- **项目设置**：成员与项目 PAGE-F01-02.html · 项目结构 PAGE-F03-02.html · 数据导入导出 PAGE-F03-03.html · 审计与证据包 PAGE-F17-01.html
- **公司**（仅公司管理员可见；原型以公司管理员身份展示时显示，以其他身份展示时省略）：项目管理 PAGE-F01-01.html · 公司模板 PAGE-F03-01.html · 公司经验库 PAGE-F09-01.html
- 底部：个人设置 PAGE-F02-03.html

全局页面（登录 PAGE-F02-01、邀请落地 PAGE-F02-02、无权限 PAGE-F01-03）不使用外壳，采用居中单卡布局。我的待办、项目管理、公司模板、公司经验库、个人设置使用外壳，但工地切换器显示「全部工地」。

## 演示身份
每页右上角放一个小的「演示身份」切换器（`<select>`），选项为业主、业主代理人、项目经理、设计经理、质检、预算专员、公司管理员。requirements rev2 起增加「业主方成员」（只读，示例人员 钱工，AC-F01-12），已加入受 rev2 影响的页面；其余页面在下次改动时补入。公司管理员在工地内只读，不显示签认、核对、放行、定价按钮（AC-F01-13）。切换后用少量脚本隐藏无权限的按钮（蓝图 §3：无权限操作隐藏、不置灰）。默认身份取最能体现本页主操作的角色。

## 交互
- 不可撤回操作（签认、放行、驳回、作废、标记已覆盖、标记已付）点击后打开 `.mask` + `.dialog`，用 `.confirm-summary` 列出将提交的内容，二次确认后显示 `.toast`，相关印章加 `.just` 动画。
- 列表分页，每页 20 条。表单在提交时校验，字段错误用 `.field.invalid` 和 `.err` 显示。
- 图标使用内联 SVG（`<svg class="icon" viewBox="0 0 24 24">…</svg>`，线性风格），禁止 emoji。
