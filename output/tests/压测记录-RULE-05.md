## 过程中的优化（首轮未达标）
- 首轮 P95 3.6 秒：检查点列表每次整表建模 5000 个对象（单次 0.35 秒）→ 改为先按列取派生标签与排序所需字段，再为当前页取完整数据（单次 0.06 秒）。
- 第二轮 P95 1.39 秒：待办计数每次构造全部待办 → 待放行类改为数据库计数；待放行待办改为按列取数，时区换算改用固定 ZoneInfo（待办计数单次 0.15 → 0.03–0.05 秒）。
- 证据包原先整包在内存中生成并复制 → 改为临时文件 + 流式存储与下载，由 worker 执行。
